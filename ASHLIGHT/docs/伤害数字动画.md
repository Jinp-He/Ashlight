# 伤害数字动画（2026-11-03确认）

- 字号保持当前组件原值。每段结算的类型标签、实际生效数值、无效行是一组。
- 护盾抵挡和其他抵消统一显示浅灰“无效 -N”；全无效时只显示该行；施加出血等状态不生成数字。
- 中心锚点在目标单位ActivationShape顶部向下170px内随机生成；默认范围160×170，单位局部坐标x=-80..80、y=-290..-120。各段锚点最小间距30px；贴图大小不参与计算。动画越出判定框是允许的。
- 从锚点下方15px开始，0.2秒弹到锚点、放大至1.2倍；0.2秒回到原尺寸；再停留0.8秒；最后0.2秒淡出。参数位于DamageNumber组件的export变量。
- 多段攻击逐段显示，沿用受击错峰间隔0.1秒；逐段计算剩余护盾。组内所有行同时运动。
- 演出组等待最后一段数字停留结束和其他演出结束。淡出独立于演出组存活，不占用操作锁。敌方队列仍按从左到右串行执行。
- 出血、中毒结算数字也使用同一动画和锚点规则。暴击、未命中、额外抵消条件仍由未来卡牌/敌方行为提供，本次不新增判定机制。

验证场景：`tests/damage_number_popup_test.tscn`。


最新节奏：演出组2及数字动画时长统一乘1.15。数字弹起0.23秒、回弹0.23秒、停留0.92秒、淡出0.23秒；淡出仍不阻塞操作。仅操作锁定，抽牌/弃牌/重排动画正常播放。BattleRoot检查器可通过group2_duration_multiplier调整演出倍率。


姿态保持单独增加40%：friendly_wait与hit_hold的基准从0.5改为0.7秒，叠加既有1.15倍率后从0.575改为0.805秒。剪影切换、闪黑、粒子及数字时长不随此次调整变化。
