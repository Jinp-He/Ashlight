# 战斗设计 · 连锁牌战原型（V0.2 实装）

设计来源：《连锁牌战 GDD V0.2》+ 2026-11-02 讨论结论及 2026-11-03 规则调整。未拍板的项目先按下文「暂定」实装，数值均为占位。

## 1. 时间与动作

没有回合，也没有费用。时间只由玩家的**动作**推进；不操作时，时间停止。

| 动作 | 推进倒计时 | 抽牌 | Combo |
|---|---:|---|---|
| 出牌 | 1 | 抽牌效果另算 | +1 |
| 摸牌 | 1 | 1 张 | 清空 |
| 手牌打空自动补牌（奖励） | 0 | 补到 5 张 | 保留 |

每次敌方攻击对我方造成实际生命值伤害，Combo 减少 1，最低为 ×1。护盾完全吸收伤害时不扣；部分吸收但仍掉血时扣 1。多个敌人接连造成掉血时逐次扣减。

手牌不设十张上限。普通摸牌和抽牌效果均可让手牌超过十张，不触发弃手重抽，也不清空护盾；打空手牌的奖励补牌同样不清护盾。抽牌仍受牌库和弃牌堆中实际剩余牌数限制。

## 2. 卡牌

三名角色的牌组成一个公共牌库（15 张起始牌，每人 5 张；完整卡牌库仍为 24 张），共用手牌。

| 属性 | 说明 |
|---|---|
| 颜色 | 红 / 蓝 / 黄 / 绿，显示在卡面菱形 |
| 基础点数 | 卡表填 1–5；**抽到手时在 ±1 内浮动一次**，钳制在 1–5，离开手牌前不变 |
| 点数显示 | 菱形内显示抽到时确定的点数，之后不再变化 |
| 效果值 | 单次触发 = `点数 × 每点倍率`；抽牌等固定效果不随点数变化 |

占位定位：火炮直接伤害，艾琳出血与反制，周周护盾、抽牌与反制。

### 反制牌

没有通用的反制规则，反制由卡牌实现：

> 截击（艾琳 · 红 2）：敌人下个动作若是红色攻击：反制，并造成 5 点伤害。

- 打出后进入**待命**（左上角列出），在**任意敌人的下一个动作**时结算并消耗。
- 该动作是指定颜色的攻击：取消这次攻击，对出手的敌人造成伤害；颜色不符或不是攻击：反制作废。
- Combo ×N 会让反制待命 N 份，命中时伤害 × N。多张反制可叠加。
- 占位反制牌：截击（红色攻击 → 5）、盾反（周周 · 蓝色攻击 → 5）、拆招（艾琳 · 任意攻击 → 3）。

## 3. 接牌与 Combo

- 可出 = 与牌堆顶**同色**，或点数等于牌堆顶数字。接不上的牌在手牌区下沉并压暗。
- 开局从牌库翻一张作为牌堆顶。
- 左上角显示 **COMBO ×N**：下一张打出的牌，效果触发 N 次（演出播一次并显示合计，结算逐次执行）。
- 从 ×1 开始，每出一张合法牌 +1，最高 ×4（暂定）。连锁不再改变手牌点数。
- **摸牌**使 Combo 回到 ×1。
- 我方被敌方攻击造成实际掉血时，Combo −1，最低 ×1；护盾全挡不扣，部分挡住但仍掉血则扣 1。
- 打空手牌是奖励：免费补到 5 张，Combo 保留，不推进倒计时，不清护盾。

## 4. 敌人

- 每名敌人有独立倒计时（占位：Remy 3 / Wangg 4 / Grey 5），每个玩家动作 −1。
- 头顶显示倒计时；身下显示下一张牌（颜色、数字、名字）与**提前锁定的随机目标**。
- 归零时把预告牌打到牌堆顶（**不需要符合接牌规则**），并**当场结算**：先结算待命的反制，未被反制的攻击立即命中，护盾立即生效。
- 出手后倒计时立刻从头开始（部分牌额外 +1）。
- 敌人身下显示下一张牌的颜色、数字、名字、目标和伤害值；头顶图标里的数字也是伤害值，不是倒计时。
- 敌人的牌不进入弃牌堆，洗牌只洗角色的牌。
- 同时归零：在同一个动作里从左到右依次出手。待命的反制只对第一个出手的敌人结算。

### 怪物与意图资源

怪物属性不再写在 `MonsterDatabase` 的代码字典中。`data/monsters/*.tres` 是 `MonsterData`，字段如下：

| 字段 | 含义 |
|---|---|
| `id` | 对应场景中敌方单位的 `unit_id`；文件名为其 snake_case，例如 Remy → remy.tres |
| `monster_name` | 提示文字里的显示名称，留空时使用 ID |
| `max_hp` | 初始最大生命，开战时回满 |
| `countdown` | 开局和每次行动后的基础倒计时，至少 1 |
| `intents` | 有序的 `EnemyIntentData` 资源引用数组，按顺序循环；重复引用表示循环中重复使用 |

当前四种怪物保持原数值：

| 怪物资源 | 生命 | 基础倒计时 | 意图循环 |
|---|---:|---:|---|
| `data/monsters/remy.tres` | 30 | 3 | 斩击 → 重斩 |
| `data/monsters/wangg.tres` | 30 | 4 | 冰锥 → 雷击 → 护体 |
| `data/monsters/grey.tres` | 40 | 5 | 重锤 → 粉碎 → 装甲 |
| `data/monsters/mafe.tres` | 99 | 3 | 重锤 → 粉碎 → 装甲 |

每种意图单独保存在 `data/enemy_intents/*.tres`，可被多个怪物共享。Grey 与 Mafe 共用重锤、粉碎和装甲资源，修改共享意图会影响两者；要单独调整某种怪物，应复制意图资源并替换其引用。

| 意图字段 | 含义 |
|---|---|
| `id`、`intent_name` | 唯一标识与显示名称 |
| `color`、`number` | 打到牌堆顶的颜色和点数；敌人不受接牌条件限制 |
| `stat`、`value` | `damage`：随机锁定一名存活对手并造成固定伤害；`shield`：为自身获得固定护盾 |
| `delay` | 本次意图结算后，下次倒计时额外增加的格数，默认为 0 |

`delay` 属于**刚执行的意图**：粉碎为 1，因此 Grey 使用粉碎后倒计时为 5 + 1 = 6；随后装甲结算后恢复为基础 5。被反制的意图仍消耗一次行动、应用其 delay 并推进循环，保持原规则。

预告生成时创建独立的运行时快照，并提前锁定攻击目标；出手前目标倒下则从存活对手中随机重选。当前生命、剩余倒计时、循环下标和锁定目标不写回 `.tres`。缺失资源、ID 不匹配、非法数值、空意图或不支持的效果类型会报配置错误，不使用占位数值兜底。

编辑流程：在 Inspector 修改怪物属性、拖入或排序意图；新建怪物时建立同名 MonsterData 资源，并令场景敌方单位 `unit_id` 与资源 `id` 一致，无需注册代码字典。新增意图当前支持伤害与护盾，未开放其他效果类型。

## 5. 单次出牌结算顺序

1. 检查接牌条件。
2. 记录当前 Combo ×N。
3. 结算卡牌效果 N 次（反制牌：登记 N 份待命）。
4. Combo +1。
5. 全场倒计时 −1，出血结算。
6. 归零的敌人从左到右出手：先结算待命反制，再结算攻击（目标已倒下则随机换一名存活角色）；每次攻击造成实际掉血则 Combo −1（最低 ×1），护盾全挡不扣。
7. 手牌打空则免费补到 5 张（不推进、不清 Combo）。

## 6. 友方技能

每名友方角色有一个带冷却的技能，**放入一张当前接不上的手牌**来启动，改写这张牌后它留在手里（通常就能接上了）。

| 角色 | 技能 | 效果 | 冷却（占位） |
|---|---|---|---|
| 周周 | 变色 | 这张牌随机换成另一种颜色 | 4 |
| 艾琳 | 削减 | 点数 −1（最低 1） | 3 |
| 火炮 | 增幅 | 点数 +1（最高 9，可超过 5 去接敌人 6、7 点的牌） | 3 |

- 操作：点一张接不上的牌（抬起高亮，只有能对它用技能的友方保持亮起）→ 点该友方。再点这张牌或右键取消。
- **使用技能不算动作**：不推进敌人倒计时、不影响 Combo。冷却按玩家动作递减（出牌 / 摸牌各 −1）。
- 友方身下显示技能名、就绪 / 冷却和效果说明。角色倒下后技能不可用。
- 数值与冷却配置在 `battle/scripts/v2/ally_skills.gd`。

## 7. 角色与胜负

- 生命值每人独立（占位 60），护盾属于个人。
- 角色倒下后，他的牌仍留在牌库：**可以照常打出用来接牌、推进时间、累积 Combo，但没有效果**（点任意存活单位即可打出）。
- 全部敌人倒下胜利，全部角色倒下失败；战斗结束后不能再出牌或摸牌。
