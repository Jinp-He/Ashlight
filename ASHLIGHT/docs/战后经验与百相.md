# 战后经验与百相

## 流程与入口

入口为 `res://battle/Battle.tscn`。初始三名普通怪物与后备精英全部击败后，共获得5张经验牌。回收战斗手牌，点击经验牌再点击角色，或拖到角色判定框。右键或无效落点取消，不消耗经验。

每名角色本场首次获得经验触发一次选牌；升级使用当前等级×2经验，保留溢出。顺序为升级动画、选牌、周周百相、返回分配。艾琳和火箭没有百相候选。分配结束停留场景且保持战斗输入关闭。

## 文件与配置

- `battle/scripts/rewards/victory_rewards.gd`：阶段、经验分配、共用遮罩和按钮、选择提交。
- `battle/scripts/rewards/reward_candidate.gd`：当前卡牌UI、PSD组件、悬停和退场表现。
- `battle/scripts/rewards/run_progress.gd`：运行期间状态；角色经验等级、本局牌库、百相、共享刷新次数。
- `battle/scripts/rewards/aspect_catalog.gd`：周周5个百相名称、效果和图标映射，风味文字留空。
- `data/rewards/default_rewards.tres` / `reward_config.gd`：等级稀有度权重、候选位置与尺寸、入场时长、悬停幅度、飘动幅度、按钮位置、经验牌比例与怪物经验。
- `assets/rewards/`：经验牌、PSD分离底板与旗帜、5个透明图标及导入配置。
- `battle_root.gd`：胜利入口、击败经验计数、切蓝与士气百相接点。
- `deck_manager.gd`、`hand_manager.gd`：本局牌库恢复与战斗手牌回收。
- `unit_root.gd`：连续升级保留溢出。
- `monster_data.gd`、`data/monsters/mafe.tres`：普通/精英/Boss经验分类。

`RunProgress.refresh_count/add_refreshes/spend_refresh/reset_refreshes` 管理共用刷新。`begin_battle()` 开始下一战但保留本局成长；`reset_run()` 开始新局。没有新增按钮或下一战入口。全部只存在内存，关闭游戏不保存。

确认奖励时先完成数据提交，再播放退场；退场途中重进不会重复领取，继续尚未处理的队列。
