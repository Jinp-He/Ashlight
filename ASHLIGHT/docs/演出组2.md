# 演出组2

战斗入口：`battle_root.gd::_v2_animate()`。玩家卡牌、敌方攻击/防御及反制共用此入口；旧 `CutsceneGroup` 不再从这些路径创建。旧预览场景保留。

实现：`battle/scripts/cutscene2/cutscene_group2.gd`。主动角色按卡牌类型进入 Attack / Cast / Charge；旧姿态立即转为纯白剪影，新姿态原位叠在其上，旧剪影整体淡出。敌对目标进入 Hit，使用黑剪影；同阵营目标不切 Hit。结束恢复双方演出前姿态（包括 Charge）。

- 攻击：使用提供 GIF 拆出的五张透明帧，50ms/帧；连击错峰0.1秒、随机旋转，相邻最短夹角至少45度；黑闪、衰减抖动及Hit保持。
- 状态：白色圆环0.5秒由半径10扩散到125、宽度20变0，10颗十字星向外减速缩小消失。
- 防御：白环0.5秒从125缩到50，过冲回弹，宽度2增至5.5；3颗圆点向心聚拢。等粒子最长寿命0.8625秒结束，剩余环额外淡出0.2秒。
- 同阵营默认等待0.5秒。BattleRoot检查器“演出组2”可调等待时间、剪影过渡时间（默认0.3秒）。
- 结束时间取姿态恢复完成、特效尾段结束两者的较晚者。战斗已有busy锁贯穿玩家动作和整个敌方队列，出牌、摸牌、技能均被阻止；倒计时归零的敌方按X坐标升序串行执行。

沿用原有Combo结算：一张卡只播一组演出，攻击冲击次数=卡牌段数×Combo，冲击线缩放=1+0.2×(Combo−1)。数值效果仍在演出完成后结算。

验证：`tests/battle_group2_test.tscn`覆盖敌对状态进入Hit、Charge恢复、同阵营不切Hit、防御淡出、技能锁定、敌方排序/不重叠、旧组断开；现有规则与真实出牌动画测试一并执行。
