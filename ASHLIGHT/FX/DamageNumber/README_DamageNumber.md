# 伤害数字组 · Godot 制作规范（DamageNumber）

> 配色 / 排版 / 状态规则的**唯一真相源**，供程序员落地到 `res://FX/DamageNumber/`。
> 对应可视化预览（白底、可交互切换态）：`A:\ASHlight\战斗演出预览\伤害数字组_预览.html`
> 关联组件：`cutscene_controller._spawn_damage_number`（当前为占位、默认关闭）。

---

## 0. 一句话概述

战斗中所有"飘字"统一由 `DamageNumber` 组件渲染，采用**两行结构**（第一行=类型/补充信息，第二行=数字），**真·外轮廓描边**（纯外部、不侵占字形），并按伤害类型用颜色与字号区分优先级。普通伤害**只显数字不挂标签**；非普通伤害暴击时**放大+加 `!` 且保色**；打盾/被抵消时追加浅灰**吸收/无效**小字行。

---

## 1. 字体规范

| 项 | 值 |
|---|---|
| 字体 | **字魂扁桃体**（商用字体，需确认项目已取得授权/已转为 FontFile 资源） |
| 回退 | `Microsoft YaHei` / `PingFang SC` / `sans-serif` |
| 字重 | 500（中等） |
| Godot 落地 | 作为 `FontFile` 资源（`*.ttf/*.otf`）挂到 `Label.font`；缺失时回退默认字体 |

> ⚠️ 字体授权提醒：字魂为商用字体，正式构建前需确认授权状态，否则改用免费替代字体并保持字形观感。

---

## 2. 描边规范（关键）

- **必须是真·外轮廓描边**，不是沿字形的居中描边（居中描边会吃掉字体填充、发糊）。
- **Godot 4.x 原生支持纯外描边**，直接用 `Label.outline_size` + `Label.outline_color`，无需手搓双层叠字（网页预览因 CSS 限制才用双层 hack）。
- 描边色统一为 **「黑 85% × 字体色 15%」**（比中点更偏黑，沉稳）。
- **标签（信息文字）描边与数字基础描边一致，且恒定**——数字放大/缩小时，标签描边**不跟着变**（避免小字被粗描边糊死）。

| 元素 | 外圈描边厚度（Godot `outline_size`） |
|---|---|
| 普通 / 结算 数字 | **3** |
| 暴击 数字（放大态） | **4**（取 4.5 的整数近似，或 5，见 §4） |
| 标签 / 吸收 / 无效 小字 | **3**（恒定） |

## 4. 字号与排版规范

### 4.1 两行结构
```
[第一行] 类型 / 补充信息（标签，恒定 14px，居中）
[第二行] 数字（大字）
```
- **普通伤害**：默认**只显第二行数字，不挂第一行标签**。
- 普通伤害暴击 → 归入「暴击」类型（橙色 + "暴击"标签 + 数字放大加!）。
- 标签**恒定 14px**，数字放大时标签**不放大、描边不变化**。

### 4.2 字号梯度（预览基准 px，按项目相机缩放换算）

| 元素 | 字号 | 字距（letter-spacing） | 行高 |
|---|---|---|---|
| 普通 / 结算 / 治疗 / 护盾 数字 | **34** | **-2px**（微叠效果） | 1.05 |
| 暴击 数字（放大态） | **54** | **-3px** | 1.05 |
| 标签（第一行信息文字） | **14** | **+1px** | — |
| 吸收 / 无效 行（小字） | **14** | **+1px** | 1.2 |

> ⚠️ **Godot 坑**：原生 `Label` **没有 letter-spacing 属性**。预览里的"负字距微叠"（后面数字轻微叠前面）是 CSS 特有效果。
> - 方案 A（推荐）：用正常字距，放弃微叠（最省事，观感损失小）。
> - 方案 B：用 `TextParagraph` 在 `_draw` 里手动排布字符串（可设字间距），成本较高。
> - 若选 B，字距参数：普通 -2、暴击 -3、标签/吸收 +1。

### 4.3 正负号约定（无障碍）
- 伤害数字带 `-`（如 `-199`、`-512!`）
- 治疗 / 护盾带 `+`（如 `+120`、`+80`）
- 即使色盲玩家也能靠符号区分方向。

## 5. 各类型展示规则（附结构示意）

### 5.1 普通伤害
```
-199
```
- 仅数字，红色 `#e22600`，34px，无标签。
- 命中护盾时追加浅灰「吸收 -N」行（见 §6）。

### 5.2 暴击伤害
```
暴击          ← 标签 14px 恒定（橙）
-512!         ← 数字 54px 放大 + !（橙，描边加粗到 4）
```

### 5.3 未命中（MISS / 不生效）
```
未命中        ← 仅浅灰小字 14px，无数字
```
- 也可只显示文字、不出现数字（弱存在感）。

### 5.4 吸收（伤害打盾）
```
-2            ← 穿透到血量的真实伤害，走原色（普通红 34px）
吸收 -8       ← 被盾吃掉的，浅灰 14px 小字
```
- 规则：**穿透血量的真实伤害用其原类型色**（`-2` 红）；**盾吸收部分用浅灰 "吸收 -N"**。

### 5.5 结算·持续伤害（如灼烧/出血/中毒）
```
灼烧          ← 标签 14px（邪紫），动态显示状态来源名
-36           ← 数字 34px（邪紫）
```
- 标签 = 动态来源（`灼烧`/`出血`/`中毒`…），强调"这是持续 tick，不是这一下"。
- 暴击态（见 §7）放大加!，颜色不变。

### 5.6 治疗
```
治疗          ← 标签 14px（绿）
+120          ← 数字 34px（绿）
```

### 5.7 护盾
```
护盾          ← 标签 14px（蓝）
+80           ← 数字 34px（蓝）
```

## 6. 吸收 / 无效 态（打盾 / 抵消）

- **伤害打盾**（普通 / 暴击 / 结算）：在对应数字下方追加浅灰 **「吸收 -N」** 行（N = 被盾吸收量）。
- **增益被抵消**（治疗 / 护盾）：在对应数字下方追加浅灰 **「无效 -00」** 行（表示效果未生效）。
- 样式统一：浅灰 `#A3A8B4`，**14px，字距 +1px，描边外圈 3px**（与标签完全一致）。
- 此行由结算数据中的 `absorbed_amount` / `blocked` 字段控制显隐（见 §9）。

---

## 7. 暴击态规则（非普通伤害）

- 触发对象：**任意非普通的伤害数值**（结算 / 治疗 / 护盾）暴击时。
- 表现：数字**放大 34 → 54px**、**末尾加 `!`**、描边**等比加粗 3 → 4**（外圈），**颜色完全不变**。
- 标签（第一行中文）**恒定 14px、不放大、描边不变化**。
- 普通伤害本身不套用此规则（普通暴击归入「暴击」类型，已是橙色独立展示）。
- 由结算数据中的 `is_crit` 字段控制（见 §9）。

---

## 8. 动画规范（当前）

- **不做差异化动画**（用户明确）。当前仅静态飘字。
- 预留接口：未来如需差异化（暴击弹跳/粒子、miss 抖动快淡、治疗柔光），可在 `DamageNumber` 上挂独立的动画资源，不影响配色/排版。

## 9. 数据契约（程序员的结算入参）

`_spawn_damage_number(unit, payload)` 的 `payload` 建议结构：

```gdscript
# 伤害数字结算数据契约
{
  "type":      "normal" | "crit" | "miss" | "absorb" | "tick" | "heal" | "shield",
  "value":     int,            # 伤害为负、治疗/护盾为正（含正负号显示）
  "is_crit":   bool,           # 非普通类型的暴击放大加!（见 §7）
  "source":    String,         # 仅 tick 用：状态来源名（灼烧/出血/中毒…）
  "absorbed_amount": int,      # >0 时追加浅灰"吸收 -N"行
  "blocked":   bool            # 增益被完全抵消 → 追加浅灰"无效 -00"行
}
```

映射示例：
- 10 伤打 8 盾 → 普通：`value=-2`（红）+ `absorbed_amount=8`（灰"吸收 -8"）。
- 结算灼烧 36 打盾 5 → tick：`value=-36`（紫，`source="灼烧"`）+ `absorbed_amount=5`（灰"吸收 -5"）。
- 治疗 120 被抵消 → heal：`value=+120`（绿）+ `blocked=true`（灰"无效 -00"）。

> 注：预览里的"添加吸收/无效"和"暴击"两个切换按钮，仅用于可视化验证各态组合；实际由上述字段驱动，无需手动切换。

## 10. Godot 落地建议（组件接口）

```gdscript
# DamageNumber.gd  （extends Node2D 或 Control，挂在受击单位上方）
class_name DamageNumber
extends Node2D

@export var font: FontFile                 # 字魂扁桃体资源
@export var base_size: int = 34            # 普通数字基准字号
@export var crit_size: int = 54            # 暴击放大字号
@export var label_size: int = 14           # 标签/吸收/无效小字
@export var outline_base: int = 3          # 基础描边厚度
@export var outline_crit: int = 4          # 暴击描边厚度

# 公开调用
func spawn(payload: Dictionary) -> void:
    # 按 §3~§9 的规则，构建两行 Label（或 TextParagraph），设置颜色/字号/描边
    # 非普通 + is_crit → 放大加!保色
    # absorbed_amount>0 → 追加浅灰"吸收 -N"
    # blocked → 追加浅灰"无效 -00"
    # 当前无动画：显示即静止，等待上层 CutsceneController 控制生命周期
```

- 颜色常量直接对应 §3 表（字色 + 描边色两组 `Color`）。
- 描边：`Label.outline_size` = `outline_base`/`outline_crit`，`Label.outline_color` = 对应描边色。
- 接入口：`cutscene_controller._spawn_damage_number(units, ...)` 中，按 `payload` 调用 `DamageNumber.spawn()`。
