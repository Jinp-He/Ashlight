## 二、播放流程（时间线）

### ▶ 阶段 1：开场（动画开始）

- **YAYA 动画**：开始**循环播放**，并以 **淡入（Alpha 0 → 1）** 方式入场。
- **BlackCurtain 动画**：与 YAYA 同时启动，按 **01 → 02 → 03 → 04 → 05** 顺序播放（正序）。
- 此时黑幕读条进入**读条保持**状态。

### 🔄 阶段 2：读条中（持续，等待加载）

- **BlackCurtain**：保持在读条完成状态（停在最后一帧 `Anim_BlackCurtain05`，或按读条需求循环最后一帧），**此阶段持续时长由实际加载进度决定**。
- **YAYA 动画**：持续**循环播放**，不受读条影响。
- **阶段结束条件**：当实际加载完成时，结束黑幕阶段，进入阶段 3。

### ◀ 阶段 3：读条结束

- **YAYA 动画**：以 **淡出（Alpha 1 → 0）** 方式退场，停止循环。
- **BlackCurtain 动画**：**倒叙播放**，按 **05 → 04 → 03 → 02 → 01** 顺序回放，回到起始黑幕状态。

## 三、图层与层级关系

| 层级 | 内容 | 混合/备注 |
|------|------|-----------|
| 顶层 | BlackCurtain（转场黑幕） | 覆盖全屏，作为转场黑幕 |
| 底层 | YAYA 动画 | 在黑幕下方/内侧循环播放，受黑幕遮罩控制可见性 |

> 说明：YAYA 在黑幕转场期间于画面中持续呈现（黑幕可半透明或局部露出），转场结束后随黑幕退场一起淡出。

## 四、状态机（落地参考）

```
[Idle]
  │ 触发开场
  ▼
[Phase1_Opening]  ── YAYA 淡入 + BlackCurtain 正序(01→05)
  │ 读条开始保持
  ▼
[Phase2_Loading]  ── YAYA 循环 + BlackCurtain 保持(05)
  │ 实际加载完成 → 结束黑幕阶段
  ▼
[Phase3_Closing]  ── YAYA 淡出 + BlackCurtain 倒序(05→01)
  │
  ▼
[Idle] / 进入下一场景
```

## 六、备注

- **BlackCurtain 动画本身仅作转场黑幕播放功能**，其帧序列不反映真实加载百分比（按固定节奏播放正序 + 倒序）。但**黑幕保持阶段的时长由实际加载进度决定**：加载完成即结束黑幕阶段、进入退场。
- **YAYA 动画不与加载进度绑定**，持续循环播放，由过场状态机统一调度起止。
- YAYA 与 BlackCurtain 应作为**独立图层/独立播放器**驱动，便于分别控制淡入淡出与正倒序。
- 倒叙播放（阶段 3）直接复用同一序列反向遍历即可，无需额外资产。
