## 生命周期规则

1. **新想法进草稿层**；拷问定稿后升定稿层，同一提交更新本页索引。
2. **机制重构后跑对账**：只修订规则书；被推翻的设计稿在同一提交里打头部 ⚠️ 标注 + 改 `废弃_` 前缀 + 挪 archive/。
3. **部分失效 ≠ 废弃**：只废章节的在头部标注失效范围（例：起手卡组设计），整篇失效才归档。

## 头部状态块规范（每份文档四行）

> 状态：脑暴 / 设计稿 / 定稿 / 部分失效 / 废弃
> 日期：定稿或标注日
> 上游基准：与谁冲突时听谁的
> 替代关系：取代了谁 / 被谁取代
