## 2. 坐标系约定

- 设计基准分辨率 **1600 × 900**（宽 × 高），Canvas 使用 Reference Resolution 1600×900。
- 原始 web 坐标系：原点在**左上角**，x 向右、y **向下**。
- Unity `RectTransform.anchoredPosition`：原点在**中心**，y **向上**。
  两者转换：`localX = screenX - 800`，`localY = 450 - screenY`（管理器内 `ToLocal()` 统一处理）。
- 方块、背景、特效挂在 `shakeRoot` 下（随屏幕震动整体位移）；手牌挂在 `handRoot` 下（**不**随震动位移，等价于 web 的 DOM 覆盖层）。

## 4. 各部分逻辑

### 4.1 方块滑入演出（A 进攻方 / B 受击方）
- 由 `PairXAt(t)` 计算 pair 中心 X，按时间分三段：
  1. **进场**：从屏幕外（我方左 / 敌方右）以 `slideSpeed` 滑到慢速区入口。
  2. **慢速区**：在画面**居中**、宽 `slowWidth` 的区间内以 `slideSpeed × slowFactor` 爬行，停留最久。
  3. **退场**：以 `slideSpeed` 飞出屏幕外后销毁。
- **A 恒在 B 左侧**（A-B 相对顺序恒定）；仅整体移动方向随 `direction` 翻转（镜像对称，二者 X 之和恒等于 1600）。
- `t < spawnDelay` 时方块不出现（生成延迟）。

### 4.2 慢速区
- 仅作视觉参考标识（原 web 画了两侧虚线 + 半透明带），**不参与运动计算**，宽度由 `slowWidth` 决定、居中于 800。

### 4.3 插入特效序列（多实例并发）
- 14 帧全屏宽序列帧（`anim_CutsceneEffect_01`~`14`），**原生尺寸播放、不调速不缩放**。
- **与方块同步**：特效从方块出现瞬间（`spawnDelay` 后）开始，按 `effectFps` 顺序播放 1→14，播完即隐藏（无淡出/定格/停顿）。
- **敌方翻转**：`direction == enemy` 时整层水平翻转（`scale.x = -1`），扫击方向反转。
- **层级**：位于 AB 方块下方（z 序靠后）。
- **多实例叠加**：每次触发都新建一个 `CutsceneEffect` 实例加入 `activeEffects`，旧实例自然播完才移除，**新实例叠在旧实例之上**（列表顺序 = 绘制顺序）。连续打出多张牌时互不打断。

### 4.4 屏幕震动
- 触发：随每一次「演出特效触发」产生（见 4.6）。
- 力度曲线：触发后先等 `shakeDelay` 秒，起手瞬间力度 = `shakeAmp`，之后按 `1 - 已过时间/shakeDuration` **线性衰减到 0**。
- 取所有活跃特效实例中的**剩余力度最大值**（新触发会重新拉满，叠在旧震动之上）。
- 位移：`shakeRoot` 每帧随机偏移 ±amp（x、y 独立随机）。
- 防穿帮：背景 `Img_BattleBG` 按 `shakeAmp` 外扩绘制（`size = 1600+2·amp, 900+2·amp`），避免位移后露出边缘空隙。

### 4.5 手牌系统
- **生成点 / 回收点**独立可调：抽牌从 `spawnPoint` 飞入，打出飞向 `recyclePoint`（牌库）。
- **抽牌序列**：`DealHand()` 把全部牌重置到生成点（缩到 0.12），然后逐张（间隔 `handStaggerMs`）飞入手牌并居中排列；全部入场后自动切换 `compactGap` 紧凑。
- **悬停反馈**：悬停牌放大 `hoverScale` 并上移 `hoverLift`；其左右邻牌各平移 `(hoverScale-1)·cardW/2` 让位，**两侧间距保持不变**（用「在手牌中的槽位序号」而非原始序号，避免打出后错乱）。仅在确有悬停牌时才施加变换。
- **点击打出**：`PlayCard()` 把该牌飞向回收点并标记 `Played`，剩余手牌重新按 `handGap` 展开居中，同时触发一次演出（4.6）。
- **卡牌尺寸**：`cardW/cardH` 决定原始大小，悬停时 `hoverScale` 决定高亮大小，均为可调参数。

### 4.6 演出触发链路（一次性播放）
- 初始为**待机**（`InitIdle`）：不自动播放。
- 两种触发方式：
  - 点击手牌「打出」→ `PlayCard` → `SpawnEffect()` + `PlayOnce()`。
  - 手动点「播放/预览」→ `PreviewOnce()` → `SpawnEffect()` + `PlayOnce()`。
- `PlayOnce()`：重置时间轴 `time=0`、`playing=true`、`oneShot=true`，播放**一个完整循环**后自动暂停并停在起始帧（不进入自动循环间隔）。
- 特效实例使用**独立时钟**（按 `Time.deltaTime` 累加 `age`），即使演出时间轴已暂停，正在播放的特效也会自然播完才消失。

## 5. Unity 工程接入

### Canvas 设置
- Canvas Scaler → UI Scale Mode = `Scale With Screen Size`，Reference Resolution = `1600 × 900`，Screen Match Mode = Match Width Or Height（0.5）。
- 层级（从下到上）：`shakeRoot`（背景 → 特效层 → 方块 A/B）在最底层，`handRoot`（手牌）在顶层且不随震动。

### 预制体
- **effectPrefab**：一个空 GameObject，挂 `CutsceneEffect` + `Image`（CutsceneEffect 与 Image **同 GO**）。Image 用 `anim_CutsceneEffect_01` 占位，Pivot = (0.5, 0.5)，Raycast Target 关闭。运行时由管理器换帧。
- **cardPrefab**：一个空 GameObject，挂 `HandCard` + `Image`（作为卡面），子节点放一个 `Text`（卡号）。Pivot = (0.5, 0.5)。

### 挂载（BattleCutsceneManager 组件）
- `shakeRoot` → 震动容器 `RectTransform`
- `bgImage` → 背景 `Image`（Img_BattleBG）
- `blockA` / `blockB` → 红/蓝方块 `RectTransform`
- `effectLayer` → 特效实例父节点 `Transform`
- `effectPrefab` / `cardPrefab` → 对应预制体
- `handRoot` → 手牌容器 `RectTransform`
- `effectFrames` → 拖入 `anim_CutsceneEffect_01` ~ `14`（顺序不可错）

### 依赖
- `UnityEngine.UI`、`UnityEngine.EventSystems`（手牌指针事件）。
- 未使用 DOTween 等外部库，手牌位移用 `Vector2.Lerp` 平滑插值近似原 web 的 CSS 过渡。

## 6. 已知近似 / 假设（与原 web 的差异）

1. **特效水平对齐**：web 将整帧左对齐（`drawImage(img, 0, …)`），Unity 版为**居中**绘制（更稳健，小首帧也居中显示）。如需严格左对齐，将特效 `anchoredPosition.x` 改为 `-W/2` 并设 Pivot.x=0。
2. **手牌过渡**：web 用 `cubic-bezier` 缓动 + 逐张 stagger；Unity 版用指数平滑插值 + `WaitForSeconds` 实现 stagger，手感接近但非逐帧一致。
3. **方块/A-B 字母标签**：web 在方块上画了「A」「B」字；Unity 版默认只上色（红/蓝），如需标签给方块加 `Text` 子节点即可。
4. **坐标转换**：所有 web 屏幕坐标均经 `ToLocal()` 转局部坐标，已逐项核对（方块、特效、手牌生成/回收点、悬停上移符号）。
