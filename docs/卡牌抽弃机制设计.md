## 1. 设计动机

这是一个**多角色**游戏。原本采用「能量 + 卡牌」（类杀戮尖塔）的资源系统，但在多角色场景下，**每个角色单独算能量太累、上手门槛高**。

> **核心目标：砍掉能量，把「每回合能做什么」简化成一条好懂的规则，降低多角色的心智负担。**

---

## 2. 机制定案

| 项 | 定案 |
|---|---|
| **资源系统** | **取消能量**（不再有费用） |
| **行动单位** | 每个角色有**独立回合**，RPG 式节奏（轮到谁谁动） |
| **每回合可打** | **1 张主牌 + 任意张迅捷副牌** |
| **主牌** | 攻 / 防 / 移（保底基础款，每回合白给）+ 牌库抽到的**更强力主牌**；每回合只有 **1 个主牌名额，二选一** |
| **迅捷副牌** | 纯护盾 / 伤害，做补充，**数量无上限** |
| **手牌处理** | 回合结束**全部弃掉，下回合重抽**（不留牌、不囤牌） |
| **成长钩子** | 基础动作（攻/防/移）可通过强化**升级为迅捷** → 不再占用主牌名额 |

---

## 3. 关键决策与理由

### 3.1 为什么迅捷「无上限」却不会失控
因为采用了**「回合结束全弃、下回合重抽」**（暗黑地牢 / 杀戮尖塔式）。
玩家**攒不起一大手迅捷牌**，物理上一回合就甩不出过量护盾/伤害，所以无需给迅捷设硬上限。
> ⚠️ 这两条是**绑定**的：一旦改成「手牌可保留/囤积」，「迅捷无上限」就会崩，必须同时加别的刹车（如小手牌上限）。

### 3.2 每回合的核心抉择
唯一的主牌名额：**打基础攻/防/移，还是打这回合抽到的强力主牌？**
这个二选一的取舍，是本套战斗的主要乐趣来源。

### 3.3 成长爽点
把基础动作升级成迅捷 → 解放主牌名额 → 后期能打出「1 主 + 一串迅捷」的强度。
这是玩家在游戏中**变强的体感**之一。

## 4. 挂起项（暂不实现）

### 洞2：「强力主牌一回合只能用一张，多了会浪费」
- **现象**：每回合只能打 1 张主牌，若卡组塞了很多强力主牌，多余的（在全弃方案下）会被弃掉浪费。
- **当前决定**：**先按「少而精的主牌 + 一堆迅捷」走，不加阀门。**
- **备用阀门（未来视体验再加）**：允许「花某种代价打第二张主牌」。
- **理由**：这是可逆决策，属数值/构筑层面，不影响骨架；现在硬做反而把系统搞复杂，也可能发现根本不需要。
