### 敌人索敌重做：单轨制 + 空排 miss + 悬停抛物线
按新思路把敌人节奏从「双趟」压成「单趟」，并补齐动态索敌表现：

- **敌人单轨制（砍掉思考回合）**：原来敌人先跑规划轨亮意图、再跑执行轨等 `ExecutingCost` 格才落地（双趟，太长）。现改为**一趟**：开局/上次行动结算后**当场**选技能+锁目标+亮意图，退到执行轨第 `ExecutingCost` 格，走到 0 直接结算。抽 `UI_BattleScene.DeclareEnemyIntentAndQueue` 复用于 bootstrap / 结算后重报 / 规划轨兜底；敌人不再显示「思考」态。
- **空排 miss**：`ZoneTargeting.FilterByZone` 加 `strict` 参数——空区不再回退全体。`ResolveExecutionTarget` 改 strict 且锁定目标改为**显式入参**（`lockedTargetId`，原来错读 `UnitState.PendingTargetId`，单轨路径根本没设）。命中一刻目标区空排 → `ExecutePendingEnemyAfterExecutionTrack` 返回 `EnemyIntentResolveResult.Missed` → 敌人头上飘「MISS」（`BattleAnimationHandler.ShowFloatingLabel`）。群体技 `DamageCommand` 也走 strict：只打区内剩余、整排空才落空。
- **预告期动态重索**：`BattleManager.RefreshPendingEnemyIntentTargets`（`UpdateAllUnitsDisplay` 里调）——玩家移动后，原锁定目标离开目标区则区内改选、空区清空、有人进区则重新锁定，并刷新意图坐标/抛物线。
- **悬停抛物线**：`IntentionView` 复用玩家出牌的 `TargetArrowRenderer` 画贝塞尔；hover 意图时从敌人指向锁定角色当前 UI 位置（红色示意来袭），移出收起。`IntentionView.TargetTransformResolver` 由 `UI_BattleScene` 注入 UnitId→角色 Transform。
- 编译通过（Assembly-CSharp，0 warn 0 err）。**待在 Editor 里实测手感**（ExecutingCost 现在=预告窗口格数，可能需在表里调小）。
