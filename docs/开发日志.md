### 敌人技能「目标分区」索敌系统（第一步落地）
主题「两区走位」的地基。分数据 + 代码两层：

**数据层**（Luban 导表）
- `__enums__.xlsx` 新增枚举 `TargetZoneEnum`：`Front / Back / Any / Conditional`。
- `#EnemySkillInfo.xlsx` 新增列 `TargetZone`；14 条敌技按描述填好分区（近战→Front / 远程·控制→Back / 全体AoE·自身buff→Any）。
- 正交设计：`TargetType`(单/群) × `TargetZone`(分区) 组合，如 `AllEnemy+Front`=群扫前排。
- 导出 `TargetZoneEnum.cs` + `EnemySkillInfo.cs`(+TargetZone字段) + `enemy_tbenemyskillinfo.json`。

**代码层**（索敌真正生效）
- 新建 `Core/Data/ZoneTargeting.cs`：`FilterByZone(units, zone)` 统一分区过滤，前/后区筛选，Any/Conditional 不过滤，空区暂回退全体。
- `DamageCommand` 加 `TargetZone` 字段，AOE 扩散按区过滤（玩家卡默认 Any 不受影响）。
- `EnemySkillToTimelineConverter` 把 skill 的 `TargetZone` 传进 `DamageCommand`。
- `BattleManager.TryPickEnemySkillAndTarget` 载体目标改为按分区选。
- **动态索敌**（关键）：`BattleManager.ResolveExecutionTarget`——目标在「执行那一刻」按当前站位重解：原目标仍在区内则继续打、被移出/死亡则改选该区其他人；AOE 本就在执行时现算。→ **移动躲伤害真正生效**。

**下一步**：意图 UI 表达目标区（让玩家看得出敌人打哪区）；嘲讽覆盖索敌；Conditional 规则；空区改真 miss。
