# 一牌一行动：节奏原型

## 进入方式

在 Unity 中打开并运行：

`Assets/Scenes/BattleScene_TempoPrototype.unity`

该场景由正式 `BattleScene` 复制，但只有场景名为 `BattleScene_TempoPrototype` 时才会启用实验规则。正式场景、正式卡表和存档卡组不受影响。

## 实验规则

- 每名角色每次行动只能成功打出 1 张牌，之后自动结束行动。
- 卡牌左侧费用同时代表行动间隔：当前公共回合 + 费用 = 该角色下次行动回合。
- 不出牌直接结束时，行动间隔固定为 2。
- 原型卡的印刷费用固定，费用修改、首张移动免费等正式规则不会改变它。
- 原型战斗关闭存档升级、受伤血量继承、过载延迟和随机天气。
- 执行牌仍保留第二个时钟：`ExecutingCost` 决定效果何时落地，卡牌费用决定角色何时再次行动。

## 内容

- 12 张实验卡：法师、战士、游侠各 4 张，每张放入牌组 2 份。
- 法师费用 1～4，包含一张“执行 2 / 行动 3”的双时钟牌。
- 战士费用 1～3，测试快速防御、中速攻防一体和慢速重击。
- 游侠费用 1～2，测试用高行动频率替代同一手番的零费连打。
- 2 个实验敌人、6 个技能；技能 `ExecutingCost` 作为意图预告窗口/技能 CD。
- 节拍处刑者按 CD 1 → 4 → 3 循环，制造“快速小伤害 / 可反应重击”的对比。
- 迟滞观测者按 CD 2 → 3 → 4 循环，并用推迟效果干扰玩家行动安排。

独立配置位于：`Assets/Resources/Config/Prototype/`。

## 当前实测结论

- 目前费用确实会改变角色返场位置，但多数卡牌仍是彼此独立的即时收益，因此行动顺序改变后，实际决策差异还不够大。
- 下一轮设计应优先强化“赶在敌人意图前行动”“不同角色先后顺序产生奖励”“敌人针对快慢行动进行反制”三类机制，而不是先扩充完整卡表。
- 原型牌暂时复用所属角色的正式卡图：法师只使用法师卡图、战士只使用战士卡图、游侠只使用游侠卡图；效果与图片不要求一一对应。

## 建议观察

1. 玩家是否会因为下一次行动位置而放弃当前数值更高的牌。
2. 费用 1 的牌是否形成明显主导策略；若超过约 70% 的选择都为费用 1，应降低其收益或提高敌人的反制价值。
3. 战士失去同回合多牌组合后，攻防一体牌是否仍有满足感。
4. 游侠的“多次轮到我”是否能够替代原来的“一个回合连打很多张”。
5. 法师执行牌的“效果落点”和“下次行动点”是否容易同时理解。
6. 敌人 CD 1/2/3/4 是否形成了清楚且可利用的反应窗口。

判定这个方向有潜力的核心信号是：玩家能明确说出“我选择这张较弱的牌，是因为我需要更早回来行动”，而不是只按伤害/护甲最高值选牌。
