# 敌人压迫感设计 v1（可干扰意图下的敌人智能）

> 状态：grillme 拷问产出（2026-07-10），**定稿共识**。
> 命题：敌人意图可被打断/延迟/打空的前提下，玩家干扰工具又多又便宜，如何保持压迫感。
> 基于 [[规则书_角色卡牌设计]] v2（公共回合时钟、两区站位、破韧/嘲讽/闪避）与 [[天气系统设计_v1]]（雷暴=ATB 虚拟单位）。
> 相关代码：`Assets/Scripts/Battle/BattleManager.cs`（意图轴/技能选择）、`DataTables/Datas/Enemy/*`。
> **不改动**已定稿的分区索敌/动态索敌规则——本文新增的都是索敌之外的属性与编排规则。

**核心公式：压迫感 = 排班表的数学（密度＞答案）× 明账的恶化（坚毅＋天气）× 组合的轮换（兵种编排）。敌人全程不需要真的聪明。**

---

## 1. 八条定案

### 1.1 压迫感类型：取舍为主，时钟调味

- **取舍压迫（主轴）**：每轮威胁数 ＞ 答案数，玩家永远在选「这刀我吃，那刀我躲」。流血是常态，干扰工具是止血带不是无敌帽。
- **时钟压迫（调味）**：拖得越久局面越糟（天气升档、坚毅叠层）。
- **明确不做**尖峰压迫（「留答案等大招」的解题游戏）——在便宜被动答案的工具经济下会退化成必解题。

### 1.2 威胁密度 KPI

- 普通遭遇战：任意时刻钟上**活意图数 = 英雄数 + 1**（3 英雄局 → 稳定 3~4 个）。
- 精英/Boss 局：靠天气、多段意图、召唤补到 4~5。
- 这条 KPI 由**遭遇战编排**背，反向约束敌人 Speed 配置：不能全是慢速大招型，需要快速低伤怪填「意图流水」。

### 1.3 答案经济：改写便宜，删除付真钱

| 动词 | 威胁的下场 | 定价原则 |
|---|---|---|
| 嘲讽 | 转移（伤害照落，落战士身上） | 便宜，应得 |
| 延迟 | 推迟（威胁还在钟上，落进更糟的未来） | 便宜，税在时钟里（§1.7） |
| 走位出区 | 路由/偶尔真躲空（§1.5） | 能量 + 非游侠笨拙，已够 |
| 闪避 Dodge | 删除一发 | **贵价稀有品**，不白送；已有客观回合衰减，不加层数上限 |
| 打断 | 删除整个技能 | 真实成本 = 整轮输出 + 索敌自由砸在施法者上；阈值按敌人档位走 |

### 1.4 意图锁定类型（新增技能字段 `LockType`）

| 锁定类型 | 执行时刻结算 | 有效答案 | 无效答案 |
|---|---|---|---|
| **锁区 Zone** | 打声明时预告的那个区 | 走位出区、（区伤时 Dodge 只护自己） | 嘲讽拉不走 |
| **锁人 Unit** | 追着声明时的目标单位走 | 嘲讽换人、Dodge、打断 | **走位无效** |
| **全域 Global** | 全场/绝对节拍（天气雷暴已是） | 只能打断，或吃下 | 走位、闪避全无效 |

- **遭遇战 KPI 补充**：同屏活意图必须覆盖 **≥2 种锁定类型**，防止走位成万能答案。
- 锁人型是「走位税」的执行者：让全员龟一区和无脑横跳都不再是均衡解——由敌人设计收税，不靠规则硬禁。

### 1.5 走位 = 伤害路由，封盘是压迫节拍

两区结构下锁区意图只有三种局面：单区被瞄（真躲空）、双意图同区（一次移动躲两发）、**封盘**（双区各被瞄，躲不掉任何一发，但可决定谁吃哪刀）。

1. 走位的常态价值是**路由**不是免伤：脆皮挪进轻扫区、满甲战士站进重击区。
2. 配套硬规矩：**同拍锁区技能要有轻重价值差**（重击 vs 轻扫 / 单发 vs 多段 / 带 debuff vs 纯伤），否则路由无决策。锁区技能入池要**成对在轻重两档取料**。
3. 封盘频率交遭遇战节奏：普通局 1~2 次/场，Boss 局可拿连续封盘当高潮——封盘正是逼玩家掏贵价答案（Dodge/打断/嘲讽）的时刻。

### 1.6 打断后果：全额报销 + 坚毅

1. 被断的技能**整个作废**，敌人正常回钟等下轮——打断是玩家花整轮买的，赔付必须全额。
2. 每次被断，敌人叠 1 层**坚毅 Resolve**（可见 buff，永久）：每层提高破韧阈值（暂定 +30%~50%）。打断从可再生答案变成消耗品；靠断拖时间这条路会自己封死。
3. **坚毅只配精英/Boss 档**，杂兵不配、随便断（爽感保留）。Boss 可出厂自带 1~2 层，让「见吟唱就断」在 Boss 战第一分钟就不成立。

### 1.7 时钟载体：天气升档

1. 天气是「越来越糟」的标准载体：不可断、不可躲、按拍必落（现有骨架）。新增**升档**：雷暴每落 2~3 次强度 +1。
2. **恶化方向 = 挤压走位空间**（高档天气覆盖更广/更密，出区走位越来越危险），与 §1.5 的路由博弈咬合：拖得越久，封盘越频繁，路由越没得选。不是单纯涨伤害。
3. 普通无天气小局不做战内时钟，靠肉鸽层跨战斗 HP 延续兜底。**不给敌人普遍配狂暴计时器**（那是尖峰压迫工具，且三套计时账玩家读不过来）；狂暴仅保留为个别精英专属技能。

### 1.8 智能边界：意图是契约，智能在表上

- **不做反应式 AI**。取舍压迫的地基是可预测性：声明了就认账（锁区认区、锁人认人），玩家的路由计算不能被 AI 临场反悔。
- 「智能感」全部下沉为**技能表上的可读条件**（现有 `AttackConditionalCommand`/动态索敌即此路线）：「若目标区 ≥2 人改扫射」「HP<50% 下一发必吟唱」「专打闪避最低的单位」。玩家两次遭遇学会规则，规则本身变成新的取舍维度。
- 反制玩家流派的活儿交给**关卡侧兵种编排轮换**（闪避流猖狂→排全域吟唱怪），不交给敌人大脑。

## 2. 普通敌人的意图逻辑（简版设计）

**定位：意图流水的填充者。可读性 ＞ 变化性。**

1. **技能池 2~3 个，固定循环出招**，不做纯随机。轮换脚本写进 `EnemyInfo.IntentionSet`（字段已存在），例如 `轻扫A → 轻扫A → 重击B → 循环`。玩家第二次遭遇就能背出节奏——这是契约精神的地基，也让遭遇战编排能精确排出封盘拍。
   - ⚠️ 现状：`BattleManager.TryPickEnemySkillAndTarget` 是候选池纯随机（`BattleManager.cs:1584`），`IntentionSet` 脚本未被消费——实装点在这。
2. **锁定类型以锁区为主**，少量兵种带锁人（收走位税专员）；普通敌人**不配全域**。
3. **吟唱短或无**：`ExecutingCost` 1~3 格。可以被顺手断（无坚毅），断杂兵的爽感是玩家工具的基础反馈。
4. **兵种三原型**（按 §1.2 的 Speed 约束取料）：

| 原型 | Speed | 锁定 | 职责 |
|---|---|---|---|
| 填线怪 | 快（2） | 锁区·轻 | 高频低伤，撑活意图数 |
| 收税怪 | 中（3） | 锁人·中 | 追脆皮，惩罚无脑走位 |
| 炮台怪 | 慢（4~5） | 锁区·重 | 吟唱可断，给战士破韧一个稳定用武之地 |

5. **遭遇编排即压迫来源**：普通局 = 原型混搭满足两条 KPI（活意图 = 英雄数+1、锁定类型 ≥2 种）。`Encounter.StrategySet` 的权重脚本用于同一遭遇的排面变体。

## 3. 精英敌人的意图逻辑（简版设计）

**定位：规则携带者。每个精英 = 一条玩家必须学会的新明规则。**

1. **每个精英恰好一条条件规则**（不多配，读得过来），写成表上条件、UI 可见，例如：
   - 「目标区站 ≥2 人 → 单体重击改全区扫射」（惩罚龟缩）；
   - 「HP < 50% → 下一发必为吟唱大招」（后半场压迫升级，且给打断留明确窗口）；
   - 「每次有英雄移动 → 自身下次攻击 +X」（对走位流收税）。
2. **自带坚毅**：出厂 0~2 层 + 被断叠层（§1.6）。精英是坚毅机制的主要舞台。
3. **技能池跨锁定类型**（自己就要有 ≥2 种）：典型 kit = 锁人重击 + 锁区扫射 + 一发全域/长吟唱大招。保证单带精英的遭遇也满足跨类型 KPI。
4. **吟唱长**：大招 `ExecutingCost` 4~6 格——预告窗口够长，玩家有完整一轮做「砸锅卖铁断，还是认了走路由」的取舍。
5. **与天气/杂兵协同补密度**：精英局活意图 KPI 是 4~5，精英本体最多贡献 1~2 个，缺口由天气拍子和 1~2 只填线怪补——**不要把精英本体做成多动症**。
6. **出招轮换 = 固定循环 + 条件插队**：基础循环同普通敌人；条件规则触发时插队替换下一发。依然全程可预测，只是多了一条玩家要背的 if。

## 4. 实装台账（07-10 更新）

已落地（表 + 代码，**未经 Unity 实测**）：

- ✅ **新敌人套装**：技能 ES101~ES110（填线 ES101/102、收税 ES103/104、炮台 ES105/106、精英 kit ES107~110）；敌人 Enemy101~105（复用现有立绘）；遭遇 E101（填线×2+收税+炮台，普通局）/ E102（精英+填线×2）。
- ✅ **固定循环出招**：`TryPickEnemySkillAndTarget` 改为 A* 槽按表序循环（每单位独立游标），取代全池随机；旧敌人 Enemy001~006 自动获得节奏感。
- ✅ **S 槽条件插队**：`EnemyIntentionEnum.Skill0/1` 槽 = HP<50% 时插队施放，每场每槽一次（Enemy105 的 S0=灭世震击即此）。
- ✅ **坚毅 Resolve**：`EnemyInfo` 新增 `IsElite` 列；精英被打断永久 +1 层（`UnitState.TryInterruptByBuff`），下次挂 Stagger/Block 时阈值 ×(1+0.5×层数)（`ApplySelfCastBuffsOnIntentStart`）。杂兵不叠。

仍欠：

1. **Unity 实测**：轮换节奏 / S 槽插队 / 坚毅叠层的战斗内验证；意图 UI 的 Stagger 阈值 tooltip 显示的是表面值，不含坚毅放大。
2. `LockType` 字段与真·锁人（追人）意图——当前单体技能仍是「预告锁人、出区即换目标」的锁区语义。
3. Boss 出厂坚毅层数（机制已通，差配置入口，可用开场自施 BuffEffect,Resolve 实现）。
4. 天气升档节奏（每落 2~3 次 +1 档）与各档的走位挤压形态。
5. 锁区技能的轻/重成对定价（并入 [[起手卡组设计_费用模型对齐]] 重跑）。
