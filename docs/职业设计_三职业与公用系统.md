# 职业设计：游侠 / 法师 / 战士 + 公用系统

> 状态：设计共识 v1（2026-07-04，grillme 拷问产出）。作为后续做卡表 / 敌人索敌 / 百相天赋的基准。
> ⚠️ 与 [[规则书_角色卡牌设计]]（v2）冲突处**以规则书为准**，已知三处：①手牌不共享（每人独立手牌）；②卡牌类型只有两种（即时/执行，「迅捷」并入即时）；③移动模型为独立进出区（非相邻换位）。
> 相关：[[游戏区域术语]]、`Assets/Scripts/Battle/*`、card-authoring skill。

## 一、公用地基

### 1.1 经济模型（能量制）
- 队伍制（3 英雄同时参战，NvN）。每人**独立能量、独立抽/弃牌堆、在行动顺序(ATB)里独立手番**；**只有手牌全队共享**。
- 手番＝轮到你时，从共享手牌打「属于自己的」牌，打到**自己能量耗尽**为止，张数不限。
- 职业差异靠**卡的单价**自然产生：法师＝高费·少张，游侠＝低费·多张，战士＝居中。（不用硬性张数上限。）

### 1.2 过载（公用透支阀门）
- **每人每回合限 1 次**。透支＝本手番多打牌。
- 代价＝**下次行动在 Slots 队列里额外后退固定 1~2 格**（≈多让 1 个敌人抢在你前面）。固定值、不做回合内递增（每回合限 1 次已堵死连爆）。
- 定位＝通用的「+1 出牌」阀门；**各职业的大爆发差异走百相天赋，不塞进过载本身**。
- ⚠️「越用越贵/跨回合递增」留作以后实测若发现「回回过载」太无脑再升级（是当前方案的超集）。

### 1.3 两区站位系统
- **前排区 / 后排区**两个区域，每区可容纳多名英雄（非单格）。
- **敌人意图预告目标区**（重击前排 / 扫射后排 / 全体…，**不固定打前排**）→ 玩家据此**反复重排站位**把脆皮挪出被瞄准的区。复用已有「意图轴」预告。
- **移动＝敌人预告的 counterplay**，主主题「移动」由此涌现。
- 射程做**软**：大多数卡两区都够得到；站位主要是**防御性博弈**，不搞近战/远程硬锁（避免抽卡游戏「死牌在手」）。
- **摩擦（命门）**：移动必须有代价，否则每回合把脆皮全塞安全区＝无脑最优解。
  - 主：**移动要花能量**（见 1.4）＋ 非游侠笨拙。
  - 辅（按需加）：区容量上限、少数敌人反走位（`Root 禁锢` / 打人数最少的区）。

### 1.4 移动动作
- **基础移动人人有**：每角色每回合可**花能量做一次「基础移动」**（挪自己一步，不占卡），保证人人有最低自救。
- **移动牌**：牌库里也有移动牌（走一步 + 带触发效果）。
- 移动模型＝**相邻交换一步**（复用 `MovePositionCommand`）；牵动队友是特性（暴露/换位/挡刀博弈），一套空间模型走到底。
- 参照：暗黑地牢（Darkest Dungeon）的位次/换位思路，简化为两区。

### 1.5 百相（签名天赋系统）
- 定义 build 的天赋系统（数据源 `#UpgradeOptions`，升级三选一）。
- 每角色可**开局自带一条招牌百相**。例：
  - 游侠：**每回合第一张移动牌免费**。
  - 法师：**允许同回合挂 2 张执行牌**（双开执行）。

### 1.6 卡牌类型
- **即时**：立刻结算。
- **执行**：打出时只扣资源、不结算，挂到执行轨，等 `ExecutingCost` 格后生效；**每人每回合限挂 1 张**；延迟期内可能被敌人打断。
- **迅捷**：原地打、不进执行轨、保留回合。

## 二、三职业三角

### 2.1 战士 · 守护者 anchor（前排）
- **嘲讽 `Taunt`**：强行改写敌人索敌到自己，让法师/游侠不必每回合走位躲（他替队友扛）。对位游侠的「跳来跳去躲」。
- **护甲**：续航，配合 `Dexterity`。
- **打断敌人执行**：用 `Stagger 破韧` / `Block 格挡`，是**唯一稳定打断敌人大招**的人——镜像补上法师「怕被打断」。
- 定位：队伍防御与秩序核心，最好上手，但有明确身份（非白板）。

### 2.2 法师 · 延迟工具箱（后排）
- 主题＝**工具箱 × 延迟执行合流**：一大堆强力**情境答案**牌（驱散/定身/沉默/护罩/位移/点杀…），且**大多是执行类型**（延迟·预告·强力）。
- 「打得少」＝高费 ＋ 每回合限挂 1 张执行。
- **核心手感**：预告 → 保护自己的大招 → 掐时机；且**执行结算后立刻获得新回合** ＝ 灵活（出牌少但回合来得勤，`ExecutingCost` 延迟是平衡 tempo 的代价）。
- 副主题：**抽牌**（挖对的工具、提高一致性）＋ **buff/debuff**（廉价即时支援）。
- 空间：最想待**后排**、最怕 `Root` 被拖出安全区 → 和游侠/战士协作。
- ⚠️ 执行是否可被敌人打断＝**留待实测**。

### 2.3 游侠 · 机动引擎（穿梭）
- 主题＝**移动为轴心**，同时喂养战场调度与士气：
  - 周周通过卡牌成功移动一名友方角色 → 使该角色获得 1 层 **士气 `Morale`**。
  - 移动牌可以附带 **闪避 `Dodge`**、护甲或生成飞刀。
  - 士气 → 所有角色都可持有；使用伤害牌时消耗全部层数，每层使该牌每一段基础伤害 +2，或由特定卡牌转化为团队防御。
  - 循环：`移动友方角色 → 积累士气 → 用飞刀/攻击或防御牌兑现`。
- **定位：高速的战场调度者**。可以补充伤害，但爆发需要先用移动建立士气。
- 引擎化：基础移动人人有；游侠靠**移动友方角色并给予其士气（百相）＋牌库更多移动牌＋移动触发**，把战场调度升级成资源引擎。参照 DD 强盗/掘墓人。

## 三、现成可复用资产（buff 表已有）
- `Morale 士气`、`Poison 中毒`、`Dodge 闪避`、`Root 定身`（反走位）、`Taunt/Taunted`、`Stagger 破韧`、`Block 格挡`、`Channeling 引导`、`Strength/Weak/Frail/Dexterity/Vulnerable`、`Chill/Stun/Regen/Burn`、`Energized/CardCost/DrawCard`。
- 效果：`MovePositionEffect` / `MovePositionCommand`（交换前后排）、`AddToHandEffect`（生成小刀）。

1. **敌人索敌逻辑未实装**（头号前置）——整个两区站位主题压在此。需要：敌人意图带「目标区」字段 + 按区/嘲讽选目标。

3. **每回合的移动牌未加入牌库**——给各角色牌库补移动牌，游侠牌库更多。

5. **法师执行可否被打断**——留待实测定夺。
6. **数值调优**——移动能量费、毒/小刀/闪避层数等，后续用 card-authoring skill 调。
