# 地图拼图路线 Demo v0.1

> 状态：实施中（地图后端已建立；MapPanel 视图待接入）
> 日期：2026-07-27
> 上游基准：无；战斗规则以 `规则书_角色卡牌设计.md` 为准
> 替代关系：将替代此前未落地的复杂地图草案；不继承探索度、地点 Boss 或隐藏 Boss 规则

## 1. 目的

验证地图是否能承担一局冒险的路线选择：玩家通过放置数量有限的拼图地块，决定自己经过的战斗、事件与收益，并在拼图耗尽前以不同队伍状态抵达两个固定检查点。

本版本只做能完整跑通的灰盒闭环，不调数值、不做内容量，也不做地图成长系统。

## 2. 玩家流程

```text
起点
  -> 抽取并放置一块拼图地块
  -> 结算该地块的内容（战斗 / 事件 / 收益）
  -> 重复，直到连接至古国遗迹
  -> 完成古国遗迹的固定中期战斗
  -> 继续放置并结算地块
  -> 连接至灰雾深处
  -> 完成终点 Boss 战斗
  -> 本局结束

若当前阶段的拼图全部用完、玩家仍未到达该阶段指定地点：
  -> 黑雾追上队伍
  -> 立刻触发该阶段的追击 Boss 战斗（难度高于正常到达时）
  -> 本局结束
```

## 3. 地图结构

地图由网格、固定地点与可放置拼图地块构成。

- **起点：坎特伯雷**。固定建筑，占据连续 `2×2` 格；本局的初始可达位置，不结算战斗或事件。
- **中点：古国遗迹**。固定建筑，占据连续 `2×2` 格，必须通过；首次到达时进入固定的中期战斗，战斗胜利后才能继续向终点方向铺路。
- **终点：灰雾深处**。固定建筑，占据连续 `2×2` 格；到达后进入固定终点 Boss 战斗，胜利即完成本局。
- **拼图地块**。玩家从手牌中选择并放到合法网格；地块的接口决定道路可否延续，地块内容决定本次结算。
- **拼图池**。一局中可放置的拼图数量有限，是本局的路线预算与推进时限；每张在运行时随机抽取为 End、Cross、T-shaped、Straight 或 Turn 之一，不从 ScriptableObject 配牌。

地图的视觉和实际可达性必须一致：只有从起点出发、经由连续道路连接到的格子与地点，才算可到达。

## 4. 拼图放置规则

### 4.1 基本规则

1. 玩家在自己的回合拥有一组可选择的拼图地块。
2. 玩家选取一块地块，可旋转后拖放到地图网格。
3. 地块必须放在空格，且至少有一个道路接口与当前已连通道路匹配。
4. 合法放置后，地块成为地图的一部分，不能撤回。
5. 放置完成后立刻结算该地块内容，再补充下一块可选地块。
6. 每次放置都会消耗一块拼图；拼图池耗尽时，不再获得新的可放置地块。

### 4.2 Demo 中的合法性

Demo 只检查以下条件：

- 目标格在地图范围内且为空；
- 地块至少一个接口连接到玩家当前可达道路；
- 地块不得覆盖固定地点；
- 古国遗迹尚未完成时，不允许用道路连接到其后的区域；
- 灰雾深处只能在古国遗迹完成后连接。

Demo 不做死局修正、自动补路、地点重叠、分区随机生成或复杂的连接奖励。

## 5. 拼图时限与黑雾追击

拼图不是无限的道路素材，而是玩家在本局中可支配的有限行动力。每次放下一块拼图，玩家都在使用一次“继续探索或继续前进”的机会。

- 玩家在拼图耗尽前抵达古国遗迹或灰雾深处时，按正常流程触发该地点的固定战斗。
- 玩家在当前阶段拼图耗尽时，若仍未抵达该阶段目标，黑雾会追上队伍。
- 黑雾追上后，立即触发该阶段对应的**追击 Boss 战斗**；它是正常固定战斗的更困难版本。
- 追击 Boss 战斗的失败视为本局失败。Demo 中胜利后的后续流程暂不设计；可先视为 Demo 的非常规结束。

黑雾是时限的可视化表达，不在 Demo 中占据网格、逐格移动或改变已放置地块。它只需要通过地图边缘、进度条或提示持续告诉玩家：拼图余量正在减少，队伍正被追赶。

## 6. 地块内容

每块拼图地块只带一种主内容；内容在地块放下后立即结算。

| 内容 | Demo 行为 | 目的 |
|---|---|---|
| 战斗 | 进入一场普通战斗；胜利后回到地图 | 用队伍状态换取战斗奖励 |
| 事件 | 显示一个选择并立即结算结果 | 提供非战斗风险与收益 |
| 收益 | 直接给予一种局内资源或卡牌相关收益 | 让绕路有明确价值 |
| 商店/休息 | 二选一实现即可：购买局内资源，或恢复队伍状态 | 让玩家能修补队伍缺口 |
| 空白道路 | 不结算内容，只延伸道路 | 保留“直奔目标”的低收益、低消耗选择 |

地块形状与内容可独立组合。Demo 只需支持直道、弯道、三向路和死胡同等少量基础形状

## 7. 固定检查点

### 古国遗迹（中期）

- 是从起点通往终点的唯一必经地点。
- 第一次到达时触发固定中期战斗。
- 胜利后标记为“已完成”，并开放后半段地图的铺路资格。
- 若在到达前耗尽拼图，则改为触发古国遗迹追击 Boss 战斗。

### 灰雾深处（终点）

- 只能在古国遗迹完成后到达。
- 到达时立即触发固定终点 Boss 战斗。
- Boss 战斗胜利即为本局成功；若在到达前耗尽拼图，则改为触发终点追击 Boss 战斗。

## 8. 路线选择应产生的体验

玩家要在每次放置时作出简单、可读的取舍：

- **继续向前**：更快抵达下一个固定检查点，保留更多拼图余量，但获得的局内资源较少。
- **绕向支路**：多经历战斗、事件或收益，队伍可能更强，也会消耗更多拼图预算。
- **为某个收益接路**：为了修补当前队伍的具体缺口，而非为了填满地图。
- **停止绕路**：在黑雾追上前及时转向目标，避免固定战斗升级为追击 Boss 战斗。

本版本中，探索更多不会直接提高古国遗迹或终点 Boss 的难度。难度主要来自固定检查点的位置，以及玩家自己带着怎样的队伍状态抵达。

## 9. UI 最小需求

- 地图网格、起点、古国遗迹、灰雾深处清晰可辨。
- 底部或侧边展示当前可放置的地块；每块能辨认连接方向与主内容。
- 拖拽时清晰区分合法位置与非法位置；旋转后的接口实时更新。
- 显示玩家当前可达道路，并标识古国遗迹是否已完成。
- 常驻显示剩余拼图数量和黑雾追击进度；余量不足时给出明确的视觉警告。
- 放下地块前显示其内容；放下后使用简短确认或结算反馈，避免玩家误触后不知发生了什么。

## 10. Demo 验收条件

一局 Demo 能稳定完成以下过程：

1. 从起点放置若干拼图地块，且只有合法连接可落下。
2. 至少分别触发一次战斗、事件或收益中的两类内容。
3. 连接古国遗迹，完成中期战斗后解锁后半段。
4. 连接灰雾深处，完成终点 Boss 战斗并结束本局。
5. 在到达目标前耗尽拼图时，能触发对应的黑雾追击 Boss 战斗。
6. 玩家在每次落子前能看懂：这块会连向哪里、是否合法、落下后将结算什么，以及自己还剩多少拼图余量。

## 11. 明确不做

以下内容留到 Demo 验证后再讨论：

- 探索度、地点覆盖率与“探索越高 Boss 越难”；
- 地点 Boss、隐藏 Boss、拼图碎片与多结局；
- 地点交叠、混合怪池、上下半区随机地点；
- 具体格数、手牌数量、出现权重、奖励和敌人数值；
- 存档、地图生成算法、复杂防死局与美术演出；
- 黑雾逐格移动、吞噬地块、封路或多阶段追赶等扩展规则。
