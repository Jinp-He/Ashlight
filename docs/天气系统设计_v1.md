## 玩法语义

1. **随机天气**：战斗开始时从天气表按 `Weight` 全局随机一个天气。v1 只有「雷暴」一条（必中，测试期等于确定性）。遭遇表不参与（以后要做 Boss 指定天象再给 Encounter 加可选覆盖字段，优先级：遭遇点名 > 全局摇）。**不配「晴天/无天气」条目**；代码防御性允许天气为 null。
2. **绝对节拍**：雷暴每 `Period=6` 个公共回合落雷一次——第 6/12/18…回合，开战那一刻整场时刻表恒定。任何提前/延后/过载都不影响雷的位置，只影响谁站在雷上。
   - k=6 的用意：速度 2/3/4 的默认节拍（我方 1+n·S，敌方 n·S）大多踩不中 6，但过载/延迟可能把自己挪进雷点——「动了才有险」。
3. **结算时机**：雷暴是雷击回合的**第一个行动者**（同回合排序：天气 → 我方 → 敌方）。跨入雷击回合即结算，劈所有 `NextRound == 该回合` 的单位，各 `Damage=10` 点。残血单位会在行动前被劈死、本回合行动作废——敌我平等，这是 feature。
4. **伤害规则**：走普通伤害管线——**吃护甲、吃减伤类 buff，不吃闪避**（闪避语义是「被瞄准的攻击落空」，环境结算不消耗闪避层）。劈死走正常死亡清理 + `CheckBattleEnd()`（全队被雷灭=失败，最后一个敌人被劈死=胜利）。
5. **空劈**：雷击回合没人行动时雷照劈（劈空），节拍照常推进到下一个 6 的倍数。播报下限=日志 + 轴上雷暴格推进（雷暴作为虚拟单位自己占一个回合，时钟自然推进到它，不存在「静默跳过」）。

## 架构：天气 = ATB 时钟里的虚拟单位（第三方阵营）

- 挂进 `ATB._activeIcons`，`Speed = Period`，首次 `NextRound = Period`；轮到它 → 结算雷击 → `Reschedule(+Period)`。
- `AtbIconRuntime` 加 `IsWeather` 标志（第三方阵营，不伪装成敌人）：
  - 同回合排序规则改为「天气最先 → 我方 → 敌方 → Speed 小 → 注册序」；
  - `OnUnitTurn` 签名不动，处理器先按 id 识别天气再走玩家/敌人分支；
  - `IsUnitDeadPredicate` 豁免天气（否则查不到 UnitState 会被当死亡移除）；
  - 落雷占一个敌人回合同款的 pacing 槽（0.6s）。
- **没有 `UnitState`**：不进 `BattleStateSnapshot` 单位列表、不可被卡牌选中、不被 `GetAllUnits` 遍历。等思路 4（倒计时实体）做可攻击实体时再开这两扇门——虚拟单位原语是两者共享的地基。
- 「该回合行动的单位」= 结算瞬间 `NextRound == CurrentRound` 的真单位（从 ATB 图标读）。

## 数据表

`DataTables/Datas/#WeatherInfo.xlsx` → `TbWeatherInfo` → `Config/tbweatherinfo.json`（改 Excel 源 + gen.bat，不手改 json）。

| 字段 | 类型 | 雷暴 |
|---|---|---|
| Id | string | Thunderstorm |
| Name | string | 雷暴 |
| Description | string | 每 {T} 回合落雷一次：该回合行动的所有单位受到 {V} 点伤害（可被护甲抵挡） |
| IconPath | string | UI/Weather/Icon_Thunderstorm |
| Period | int | 6 |
| Damage | int | 10 |
| Weight | float | 1 |

占位符沿用 BuffInfo 约定：`{V}`=Damage、`{T}`=Period，tooltip 格式化复用 buff 替换逻辑。

## UI

1. **TurnOrderView**：雷暴格自然出现在 6/12/18…回合组（虚拟单位进 `GetTurnOrderWithFuture` 白拿）；专用 Setup 走表 `IconPath`，**缺图降级显示文字**；hover 走 `DescriptionViewController.Show(WeatherInfo)` 新重载。
2. **常驻角标**：战斗界面固定位置显示天气图标+名字，hover 同款 tooltip——全程可查询的事实来源。
3. **开场横幅**：战斗开始淡入横幅（图标+名字+一行描述），停留 ~2.5s 淡出，不阻塞操作。
4. **落雷瞬间**：只有被劈单位的现有掉血表现（飘字/血条），无全屏特效。素材确认加进游戏后再重新绘图，v1 用现有图标顶替。
5. ATB 时间轴条上雷暴也有自己的图标（虚拟单位天然如此）。

## 已知边角（留档不阻塞）

- `GetTurnOrderWithFuture` 是近似预览（不模拟过载延迟）：雷暴格位置绝对精确（常量节拍），但左右邻居继承近似误差。
- `SetNextRound` 理论上能把单位塞回当前回合——若发生在雷已劈完之后，该单位逃过此雷。现有卡牌不会触发该路径。
- `BattlePredictor` v1 不感知天气（出牌模拟不涉及跨回合推进）。
