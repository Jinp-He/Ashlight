## 1. 角色核心

Irene 不再只是“高费用、延迟结算”的伤害角色，而是把己方执行牌、敌我行动和天气当作时间轴上的事件进行编排。

| 主题 | 核心动作 | 收益 | 风险 |
|---|---|---|---|
| 顺延 | 主动推后己方执行牌 | 增伤、抽牌、充能、回声 | 施法者可能在结算前倒下 |
| 提前 | 主动拉近己方执行牌 | 救急、压缩爆发回合、立刻兑现 | 过载、额外费用、失去等待收益 |
| 天气 | 让敌人或执行牌靠近天气回合 | 借天气先手伤害制造爆发 | 己方也可能踩中天气，施法者可能先被击倒 |

Irene 的初始百相仍为“双执行”：她的一次行动中最多可以挂起 2 张执行牌。双执行只提高数量上限，不减免费用。

## 2. 已确定的执行牌改期规则

### 2.1 顺延

**顺延一张执行牌 N 格**：使一张己方在轨执行牌的结算回合向后移动 N 个公共回合。

- 执行牌原本的执行格数不计入“已顺延格数”。
- 只有己方卡牌效果造成的顺延会被`终焉倒数`等牌读取。
- 顺延执行牌不会改变施法者自己的下一次行动。

### 2.2 提前与立刻执行

**提前一张执行牌 N 格**：使一张己方在轨执行牌的结算回合向前移动 N 个公共回合。

- 若提前后仍晚于当前公共回合，执行牌继续留在行动顺序轴上。
- 若提前后到达当前公共回合，立刻移除该引线并结算。
- 若提前量超过剩余格数，也只会立刻结算一次；多余的提前格数作废。
- 立刻结算不会额外开启一次角色行动，也不会再次占用双执行次数。

### 2.3 同时到期

若一个效果使多张执行牌到达当前公共回合：

1. 先完整结算造成改期的卡牌。
2. 再按这些执行牌原本的结算回合从早到晚依次结算。
3. 原结算回合相同时，按挂入执行轨的先后顺序结算。
4. 每张执行牌只结算一次。

### 2.4 角色行动与天气不使用这条规则

- 敌我角色的行动被提前到当前公共回合时，不会插入当前卡牌的结算过程；它会在当前角色结束行动后按行动顺序继续执行。
- 本稿不设计“把天气提前到当前公共回合”的牌。天气只会被顺延，或作为其他事件的对齐目标。

## 3. 天气规则

- “下一次天气”始终指行动顺序轴上尚未结算的下一个天气事件。
- 同一公共回合的结算顺序仍为：**天气 → 己方执行牌 → 我方角色 → 敌方角色**。
- 天气已经在当前公共回合结算后，该次天气不再算作“下一次天气”。
- 下一次天气被顺延后，后续天气从新的结算回合继续按 `Period` 排期。
- 天气没有普通角色状态，不能成为伤害、护甲或 Buff 的目标。

## 8. 三条构筑循环

### 8.1 顺延复利

挂起`终焉倒数` → 用`余烬增压`或`时间复利`顺延并积累收益 → 必要时用`抢拍`收回部分等待时间 → 最终造成 24～48 点伤害。

### 8.2 提前兑现

挂起两张执行牌 → 战况变化后用`抢拍`逐步提前 → 紧急时用`提前兑现`直接结算其中一张。玩家获得即时响应，但承担过载与额外卡费。

### 8.3 天气编排

用`引雷`把敌人拉向下一次天气 → 让`连锁闪电`与天气同回合 → 用`风暴眼`保护也在该回合行动的队友。天气先造成伤害，连锁闪电随后以双倍伤害收尾。

## 9. 关键限制

- 操作己方执行牌的卡只能以仍在轨、施法者存活的己方执行牌为目标。
- `余烬增压`只能选择含伤害效果的执行牌。
- `回声咏唱`只能重复伤害、护甲和治疗；多段伤害按每一段分别减半，最低为 1。
- `观测天象`在没有天气或没有同调执行牌时仍可抽 1 张牌，但不会获得能量。
- `引雷`采用双向趋近：敌人早于天气则推迟，晚于天气则提前；不会越过天气所在回合。
- `风暴眼`的护甲在天气造成伤害前结算，早于通常的“天气 → 执行牌”顺序。
- `改天换日`先顺延天气，再提前所有己方执行牌；到达当前公共回合的执行牌在该卡效果全部完成后依次立刻结算。
- 立刻结算的执行牌仍可能因为施法者已经倒下而作废。

## 10. 实现顺序建议

1. 时间轴对象选择：以行动顺序上的 `CastId`为目标。
2. 单张执行牌提前、顺延，以及到达当前公共回合时立刻结算。
3. 在轨执行牌的临时增伤、结算后抽牌和充能。
4. 查询下一次天气回合与“当前公共回合是否结算过天气”。
5. `引雷`和`风暴眼`的天气窗口。
6. 最后实现`回声咏唱`与`改天换日`的多实体结算。
