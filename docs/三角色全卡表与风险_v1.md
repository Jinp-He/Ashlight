| 角色 | 速度 / 能量 / 抽牌 | 当前初始百相 | 战斗意义 |
|---|---|---|---|

**[士气]统一规则**：最多 3 层，跨行动保留。持有士气的角色使用会造成伤害的卡牌时，消耗全部士气；每消耗 1 层，使该牌的**每一段基础伤害**增加 2 点。多段、群体伤害只消费一次，但每一段和每个目标均获得完整加成；状态伤害与移动触发伤害不消费士气。

## 6. 可能出现的卡牌问题

以下按“先会导致错误或误测，再会导致强度失衡”的顺序列出。不是要求立刻削弱，而是实机测试时应有针对性地观察。

### P0：规则、实现与数据风险

1. **士气的“没有造成伤害就不消费”尚需按效果实际命中判定。** 当前实现已避免无合法目标时消费士气，但条件伤害牌在目标合法、条件不成立时，仍可能先消费士气。需要把消费时机绑定到“至少一段直接伤害确实将要结算”，否则“交错打击”一类条件牌会出现文案与结果不一致。
2. **复合目标和多选目标尚非现有卡表的普通表达。** “雁双飞”的自己＋另一名友方、“满场飞花”的最多三名不同友方，都需要独立目标选择流程；若退化成自动选人，玩家会失去调度意义。
3. **移动触发器必须统一成功口径。** 定身阻止移动、重复移动、整排移动、敌方移动、闪回移动、延迟移动都应走同一“成功移动一次”事件；否则周周的士气、飞刀、铁蒺藜会出现漏触发或多触发。
4. **旧步重寻需要防止复制链。** 必须排除衍生牌、闪回牌与自身，并保留“本回合最近的移动主卡”记录；否则 0 费闪回可能持续生成新的复制来源。
5. **Irene 的在轨执行牌选择需要可视化校验。** 余烬增压、时间复利、抢拍、提前兑现、回声咏唱都依赖“选择一张在轨执行牌”。需要清楚显示目标牌、剩余格数、已顺延格数、附加效果与施法者，否则玩家无法判断风险。

### P1：数值与循环风险

1. **士气会放大多段和群体伤害，峰值很高。** 满 3 层为每段 +6：Irene 的“秘法飞弹”从 3×3 提升为 9×3＝27；Zhouzhou 的“预知一击”是 0 费、对当前回合每名敌人 10 点；“十步杀一人”若重复 2 次，则是 14×3＝42 点。应分别测试单体、两目标、三目标情形，而不能只看单段“飞羽”的 10 点。
2. **跨角色士气可能让 Irene 成为最佳兑现者。** 周周移动 Irene 后，Irene 可立即用“秘法飞弹”消费 3 层士气；若当天气翻倍、易伤等修正叠加，伤害排序必须先写死。建议口径为：先给每段基础伤害加士气，再应用天气、易伤、虚弱等倍率或修正，并写入测试断言。
3. **Rocket 的过载经济可能把代价变成资源。** “超频供能”“极限超频”在 0 费下同时给能量和抽牌，“冷却循环”又能清过载并抽牌。若过载惩罚不足，这会成为无成本的手牌 / 能量循环，而不再是风险选择。
4. **0 费蓄力可能绕开能量压力。** Rocket 的四张蓄力牌均为 0 费；每回合仅一张与仅一条待结算蓄力必须在 UI 和规则层严格限制。否则“0 费护甲 / 0 费高伤”会同时吃到即时牌的行动预算。
5. **提前兑现可能抹平执行牌的等待代价。** Irene 以 1 费“提前兑现”换取立刻结算，若同时有“时间透支”补能量，就可能让长执行格的高伤牌只剩很小延迟。测试应比较：不带提前牌、带 1 张、带多张时的平均结算回合与过载负担。
6. **天气同调伤害可能过分依赖敌人密度。** “连锁闪电”在天气回合对全体敌方翻倍，既吃群体目标数又可能吃士气。小怪战与 Boss 战的强度会完全不同，需分开平衡。
7. **周周同时拥有过多低费移动与零费兑现。** “千里不留行”＋移步×3、“折返”、“旧步重寻”能快速叠满士气并喂满移动触发器；即使每张触发牌有上限，也要测同回合手牌是否稳定爆炸。
8. **“一鼓作气”把士气从个人伤害转成全队护甲，可能成为最优解。** 满士气时全体 11 点护甲的团队收益很大。需要和 Rocket 的“阵线加固”“区域装甲”比较，避免周周同时拥有最佳护甲与最佳伤害转化。

### P2：体验与卡池结构风险

1. **Rocket 的百相与卡池连接偏窄。** `FirstPushFree` 当前主要服务“震荡冲击”，而 Rocket 主体已转向护甲 / 蓄力 / 过载。若后续不增加 1～2 张单体推迟牌，百相会显得像偶发折扣，而不是角色玩法的一部分。
2. **Rocket 的护甲牌区分度需要观察。** 重型护板、护甲包、阵线加固、区域装甲、推进阵线、应急装甲都在提供护甲。需要确保它们分别服务自保、救援、前排、同排、进攻站位和蓄力窗口，否则奖励选择会退化为“谁数字大拿谁”。
3. **Irene 的操作牌存在空转手牌风险。** 手牌里没有在轨执行牌时，5 张“操作执行牌”会无法使用；初始牌组已有两张，奖励池继续加入时尤其明显。可通过最低限度的替代效果、抽牌补偿，或卡池配比控制处理。
4. **顺延与提前的认知成本高。** 角色行动、执行牌和天气都在同一公共回合轴上移动；需统一动画、颜色和日志，明确“提前到当前回合的执行牌立刻结算；角色行动则在当前角色行动结束后继续”。
5. **定身会成为周周的硬性天敌。** 它同时压制站位、士气生成与移动触发。保留“喝彩”“稳住阵脚”这种非移动入口是对的，但应测试定身敌人出现频率，避免角色整个回合无牌可打。
6. **目标描述要统一“全体”与“当前排”。** 例如“稳住阵脚”的“所有友方获得护甲；获得士气”需要明确士气归谁；“推进阵线”“区域装甲”的生效区域也应以结算时位置还是打出时位置为准。

## 7. 推荐测试清单

1. **士气矩阵**：0 / 1 / 3 层士气 × 单段 / 多段 / 群体 / 条件伤害 / 无目标，逐项断言消费与伤害值。
2. **周周连锁**：折返、紧急避险、满场飞花、旧步重寻分别验证士气、飞刀、铁蒺藜和抽牌上限；加入定身失败路径。
3. **Irene 时序**：提前到当前回合、提前超过剩余格数、多张同时到期、天气同回合、施法者倒下，验证只结算一次且顺序稳定。
4. **Rocket 经济**：至少跑 20 个战斗样本，对比有 / 无过载清除和有 / 无蓄力牌时的平均能量、护甲、手牌与伤害。
5. **三人协同**：周周给 Rocket、Irene 各叠 3 层士气后，分别用单段、多段和群伤牌兑现，确认这是预期团队上限而不是意外爆炸。
