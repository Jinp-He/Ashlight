## 0. 三职业动词对照（一句话身份）

| 职业 | 一句话 | 操控的对象 | 招牌机制词 |
|---|---|---|---|
| 游侠 Zhouzhou | **挪自己**——在时空里穿梭的人 | 自己的位置（空间+时间） | 移动触发 / 当前回合 / 过载透支 |
| 战士 Rocket | **撞敌人**——把敌人的时间点撞碎的人 | 敌人的时间位置 | 推迟 / 碰撞 / 打断 / 嘲讽·反击窗口 |
| 法师 Irene | **埋未来**——在轴上埋引线并掌握引爆权的人 | 未来事件（敌我的预告/执行） | 引线（执行）/ 引爆 / 顺延充能 / 拨点 |

互补关系：游侠改**自己**的坐标躲开坏时刻；战士改**敌人**的坐标制造坏时刻（碰撞/打断）；法师改**事件本身**的坐标（自己的大招和敌人的预告都是可拨动的点）。三个人围着同一条轴，动词不重叠。

引擎现状红利：`PushCollisionEffect`（推迟→碰撞→晕眩）已存在，战士主题的核心 effect 已经半实装；`AttackCurrentRoundEffect` 一族保持游侠专属，不外借。

## 1. 战士 Rocket · 「铁壁节拍」

### 主主题

三个进攻动词 + 一个防守姿态，全部长在时间轴上：

- **推**：把敌人[推迟] N 格（已有：巨龙撞击、挫志怒吼）。
- **撞**：推迟时撞上其他单位 = [碰撞]，晕眩/额外伤害（已有 PushCollisionEffect，扩展出伤害变体）。**战士是全队唯一的碰撞制造机**——把两个敌人的行动格撞在一起是他的爽点。
- **断**：打断执行/吟唱中的敌人（已有：迅猛打击×2 对执行目标；待修：InterruptCommand 接到执行轨）。
- **守**：嘲讽 + 护甲 + **反击窗口**（「直到你的下次行动」= 以格计时的戒备，参考[[时间轴玩法思路]]思路 2）。

过载签名：游侠过载=透支爆发，**战士过载=紧急扛伤**（他速度慢、退 1 格损失最小，规则书「扛旗」思想的单卡版）。

### 现有牌归位（不动）

挥砍/举盾/坚壁/重整=填充；迅猛打击/交错打击（##注释中，建议启用）=断；巨龙撞击/挫志怒吼=推撞；战吼/挺身而出/盾击=守+断；吞噬痛苦=续航。

## 2. 法师 Irene · 「引线术士」

### 主主题

她挂在执行轨上的每张执行牌是一根**引线**。核心不是「延迟=代价」，而是**延迟=可操作的资源**：

- **挂**：执行牌本体（已有：火球/炎爆/寒霜新星/冰封领域/静滞/连锁闪电）。
- **引爆**：主动让自己的引线**立刻结算**——「火球被打断很挫败」的命门由引爆权对冲。
- **充能**：反向操作，把引线**顺延**换更大威力——等得越久越疼。
- **拨点**：敌人的预告也是轴上的点，推远（拖时间）或**拉近**（拽进你准备好的窗口/让它撞别的格）。
- **吟唱态**：轨上有引线时，她的即时牌变强（已有雏形：魔力脉冲 InExecution、元素爆发 SkippedLastExecution）——挂着引线的法师处于「充能状态」，即时小牌是溢出的火花。

过载签名：**法师过载=超频吟唱**（多挂一张执行，对应百相「双执行」的临时版）。

### 现有牌归位

火球/炎爆=基础引线；寒霜新星/冰封领域/静滞=控制引线（推+定）；魔力脉冲/元素爆发=吟唱态雏形；秘法飞弹/引导/闪现=火花填充。##注释的灼热印记/法术屏障/元素涌动/凋零诅咒是无主题 StS 牌，**建议保持注释不启用**。
