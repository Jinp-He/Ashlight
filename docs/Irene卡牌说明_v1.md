## 1. 角色定位

Irene 是队伍中的高费用执行牌角色。她把强力效果挂到行动顺序轴上，在数格之后结算，并利用推迟、提前和“处于执行中”条件操控敌人的行动窗口。

| 属性 | 当前值 | 说明 |
|---|---:|---|
| 生命 | 100 | 当前基础生命 |
| 速度 | 4 | 行动频率低于高机动角色 |
| 每次行动抽牌 | 5 | 通过较大的手牌寻找合适的执行牌或时间工具 |
| 每次行动基础能量 | 4 | 通常打出一张高费用执行牌，再搭配一张低费用即时牌 |
| 初始百相 | 双执行 `DoubleExecution` | Irene 的一次行动中最多可挂起 2 张执行牌；其他角色默认为 1 张 |

双执行只提高执行牌数量上限，不减免费用。能量不足时，仍需通过能量透支或其他能量效果支付第二张执行牌。

### 1.1 核心循环

1. **挂起执行牌**：提前安排伤害、护甲或控制效果。
2. **拨动时间点**：使用推迟或提前改变敌我下一次行动的时间。
3. **读取执行窗口**：目标将在当前公共回合行动时，条件攻击获得额外收益。
4. **维持队伍节奏**：用移动、护甲、治疗、抽牌和充能弥补执行牌的延迟。

## 2. 关键词与结算口径

| 关键词 | 当前规则 |
|---|---|
| 即时 | 打出后立刻结算，不进入执行轨。配置中的类型名为 `Swift`。 |
| 执行 | 打出时支付费用并挂到行动顺序轴，在标注的执行格数后结算。结算完成后不会额外开启一次行动。 |
| 处于执行中 | 目标将在当前公共回合行动时，视为处于执行中。条件按每个目标分别判断。 |
| 推迟 N 格 | 目标的下一次行动向后移动 N 个公共回合。 |
| 提前 N 格 | 目标的下一次行动向前移动 N 个公共回合，但不会被移动到当前公共回合之前。 |
| 充能 N | 目标下次行动开始时获得 N 点额外能量，随后移除充能。 |
| 过载 N | 本次行动结束并重新排期时，自己的下一次行动额外推迟 N 个公共回合。 |
| 定身 | 角色无法移动。持续时间读取 Buff 配置，当前默认为 2 回合。定身不阻止行动提前或推迟。 |
| 前排 | 只影响当前位于前排的角色。区域内没有合法目标时，对应部分效果落空。 |

> 注意：Irene 的“充能”是下次行动获得额外能量的 Buff，不是 Rocket 的“蓄力”卡牌类型。

## 6. 典型用法

### 6.1 制造执行窗口

`拽引`可以把敌人的行动提前 2 格。当目标因此进入当前公共回合时，`魔力脉冲`、`元素爆发`和其他执行条件攻击可以获得额外伤害。提前敌人也会让其更快行动，因此这是收益与风险并存的主动操作。

### 6.2 双执行

Irene 的百相允许一次行动挂起 2 张执行牌，但基础能量仍为 4。低费用执行牌可以自然组合；高费用执行牌通常需要先打出`时间透支`，或使用能量透支支付第二张牌。

### 6.3 区域控制

`寒霜新星`只影响前排：伤害和推迟都会严格过滤到前排敌人。`冰封领域`和`凝滞领域`不限制区域，会影响全部存活敌人。

### 6.4 支援队友

`闪现`负责立即移开危险区域中的队友；`时间馈赠`让队友更早行动，并在其行动开始时提供额外能量；`时间壁垒`则提前安排全队护甲。

## 7. 实现与测试注意事项

- 执行牌在施法者倒下后会作废。
- 群体条件攻击对每个目标分别判断“处于执行中”，不是一次全体判定。
- `寒霜新星`的伤害和推迟都只作用于前排敌人。
- Irene 的行动提前、推迟效果均不触发碰撞晕眩；这些牌的碰撞结果配置为 `None`。
- 充能在目标下次行动开始时结算一次，然后移除。
- 定身只阻止前排与后排之间的移动，不阻止行动顺序变化。
- `秘法飞弹`是 3 次独立伤害，会分别经过护甲和受击处理。
- 提前效果的数据使用负位移保存，但卡面和本文均显示其绝对格数。

## 8. 与旧设计稿的边界

`卡组设计_法师战士主主题.md`记录过“引爆执行牌”“顺延执行牌并成长”“自身挂有引线时强化即时牌”等候选方向。它们目前没有进入 Irene 的正式卡池：

- 当前没有主动引爆或顺延己方执行牌的卡。
- `终焉倒数`目前固定造成 40 点伤害，不会因等待或顺延而成长。
- 当前“处于执行中”读取的是攻击目标的行动状态，不是 Irene 自己是否挂有执行牌。
- 当前“充能”只表示下次行动获得额外能量。

后续若重新启用旧候选机制，应先补充独立 Effect，再同步更新卡表、本文件和规则书。
