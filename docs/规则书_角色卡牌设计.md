# 角色卡牌设计规则书 v2

> 状态：grillme 拷问产出（2026-07-05）。在 [[职业设计_三职业与公用系统]] v1 基础上收敛出的**可落地设计框架**。
> 用途：作为三套起手卡组、数值调优、以及执行线补齐的共同基准。
> 相关：`Assets/Scripts/Battle/*`、card-effect-authoring skill。

---

## 0. 先分清两条线

整个卡牌工作拆成互不阻塞的两条线：

1. **设计线（本文）**——每张卡"是什么、花多少、打出来给谁什么效果"。设计时**按理想中的完整机制来写**，不管它现在实现没实现。
2. **执行线（phase-2）**——卡牌效果在战斗里**真正跑起来**。有一批签名机制目前是空的或接错了系统，清单见 §7。

> 一句话：设计线可以先跑在执行线前面。设计里写"移动获得闪避"，哪怕闪避现在还没被消费，也照写；补实现是执行线的活。

## 1. 经济系统：能量与手牌

### 1.1 能量池（各自独立）

- 三名英雄同时参战，**每人一个独立能量池**，轮到自己时把能量花完为止，出牌张数不设硬上限。
- 池子大小按职业分：

  | 职业 | 每回合能量池 |
  |---|---|
  | 法师 | **4** |
  | 战士 | **3** |
  | 游侠 | **2** |

- **决定"每回合打几张"的是卡的单价,不是池子大小**。池子只是"这个职业一回合大概花得起多少钱"的容器：
  - 法师池 4 = 一张 3~4 费的大执行牌（＋可能一张 1 费小支援）。
  - 战士池 3 = 两个 1~2 费的稳定动作。
  - 游侠池 2 = 主要用来付**移动**的钱；攻击牌（小刀）几乎都是 0 费,所以出牌数量由手牌/造刀决定,而非能量。

> ⚠️ 游侠的能量是**移动预算**,不是攻击预算。这条锁死了一个约束：**游侠的非移动牌基本都得是 0 费**,否则池 2 会瞬间卡死。

### 1.2 手牌（各自独立）

- 每人**独立的抽牌堆、独立的手牌、独立的弃牌堆**。每人只用自己的牌,互不干涉。
- 每回合开始把手牌补到 **5 张**。
- 打不出的牌**留在手里**,不做回合结束的强制弃牌。

> 备注：这与旧文档 v1 里"手牌全队共享"的说法不同——实际做下来是**各管各的手牌**,更干净,也不存在"快的角色把公共手牌占满"的问题。

## 2. 行动频率：速度

### 2.1 速度 = 行动间隔（值越大越慢）

- 战斗是**离散回合制**：所有单位在一条队列上排队,轮到谁谁行动,行动完按自己的**速度间隔**重新排到后面。
- **注意语义反直觉**：引擎里 `Speed` 数值其实是"间隔格数",**数值越大 = 隔越久才轮到 = 回合越少**。它更像"冷却",不是"手速"。
- 目标排序：**法师最慢 / 战士居中 / 游侠最快**。对应到数值大概是 法师≈5~6 / 战士≈4 / 游侠≈3（数值越小越快）。

  > 现有表里是 战士5 / 法师4 / 游侠3,等于把法师和战士排反了,phase-2 要改成法师最慢。

### 2.2 吞吐量 = 能量池 × 频率

- 这是整套数值的平衡等式：
  - 法师：**大池子 × 少回合** —— 攒一发大的,难得动一次。
  - 游侠：**小池子 × 多回合** —— 每次花得少,但动得勤。
  - 战士：两者都居中。
- 三个人拉长了看,总产出大致相当;区别只在**手感节奏**。

### 2.3 速度只管节奏,执行延迟单独算

- **一个动作打完后排到多远,只由速度决定**,不由这回合打了什么牌决定。
- 执行牌的"延迟 N 格才生效"是**预告窗口**,是另一码事,不参与"下次几时轮到我"的计算。
- （现状：引擎里正常回合结束是按卡的消耗格数重排的,phase-2 要改成按速度重排,把"节奏"和"延迟"彻底分开。）

## 3. 卡牌类型：只有两种

旧文档写了三种(即时/执行/迅捷),实际收敛成**两种**：

| 类型 | 含义 | 归属 |
|---|---|---|
| **执行** | 打出时只扣资源、不结算,挂到执行轨,等 `ExecutingCost` 格后才生效;延迟期内可能被打断。 | **几乎只有法师** |
| **即时**（≡迅捷） | 原地打、立刻结算、不进执行轨,能量没花完就继续打。 | 其他所有人 + 法师的廉价支援 |

- **为什么"即时"和"迅捷"合并**：在"能量花完才结束回合"的引擎下,没有任何牌会提前结束你的回合,所以旧"迅捷=保留回合"的特殊性消失了——两者都只是"立刻打"。真正有区别的只有**执行的延迟**。
- **执行轨不是只为法师服务**:敌人在这条轨上预告攻击,战士靠打断去干扰它,游侠靠闪避去躲它。**只有"玩家侧产出执行牌"这件事是法师专属**。

## 4. 三职业

### 4.1 法师 · 延迟工具箱（最慢）

- 一整套强力的**情境答案**牌(驱散/定身/沉默/护罩/位移/点杀…),而且**大多是执行类型**——延迟、预告、强。
- "打得少"来自**高费 + 每回合限挂 1 张执行**;手牌 5 张可以把答案攒在手里,等对的时机再掏。
- 核心手感:预告 → 保护自己这一发 → 掐时机。执行结算后立刻开新回合,所以是"出牌少但回合来得勤"。
- 副主题:抽牌(挖对的工具)＋ 廉价即时 buff/debuff 支援。
- 站位:最想待后排,最怕 `Root` 被拖出安全区。

### 4.2 战士 · 守护锚点（居中）

- 全部是**即时**牌,不玩延迟。靠效果拉开身份:
  - **嘲讽**:改写敌人索敌到自己,替队友扛,省得法师/游侠回回走位。
  - **护甲**:续航,配合 `Dexterity`。
  - **打断**:用 `破韧 Stagger` / `格挡 Block` 打断敌人大招——队里唯一稳定的打断点。
- 定位:防御与秩序核心,最好上手,但有明确身份(不是白板)。

### 4.3 游侠 · 机动引擎（最快）

- 全部是**即时**牌 + 大量**移动**。主题是"移动为轴,同时喂生存和进攻":
  - 移动 → 获得 **闪避 `Dodge`** 层数(躲被预告的一击)＋ **生成小刀**入手。
  - 小刀(0 费/低伤攻击,`AddToHand` 生成)→ 命中**叠毒 `Poison`**。
  - 毒 → 无视护甲慢慢磨。
  - 循环:`移动 → 闪避续命 + 攒刀 → 甩刀叠毒 → 毒杀`。
- 定位:**不是 DPS,是 utility/control/attrition**。数值可以克制,小刀低伤,爆发交给别人。
- 引擎化:基础移动人人有,游侠靠**首张移动免费(百相)＋ 牌库更多移动牌 ＋ 移动带触发**,把自救升级成滚雪球。

### 4.4 战士 vs 游侠 靠什么区分？

两个都是"廉价即时牌",**类型分不出他们**,区别**完全在效果词汇 + 池子/节奏**：

| | 战士 | 游侠 |
|---|---|---|
| 效果词汇 | 护甲 / 嘲讽 / 破韧 / 格挡 / 打断 | 移动 / 闪避 / 小刀 / 毒 |
| 池子×节奏 | 中池、中频、原地站桩 | 小池、高频、满场穿梭 |

## 5. 公用系统

### 5.1 过载（透支阀门）

- **每人每回合限 1 次**,透支 = 这手番多打牌。
- 代价 = 下次行动在队列里**额外后退固定 1~2 格**(多让一个敌人抢在你前面)。固定值,不做回合内递增。
- 定位:通用的"+1 出牌"阀门;各职业的大爆发差异走百相,不塞进过载本身。

### 5.2 两区站位

- **前排 / 后排**两个区,每区能站多名英雄。
- 敌人意图**预告目标区**(重击前排 / 扫射后排 / 全体…),玩家据此反复重排站位,把脆皮挪出被瞄准的区。
- 射程做**软**:大多数卡两区都够得着;站位主要是**防御性博弈**,不搞近战/远程硬锁。
- 摩擦(否则无脑最优):移动要花能量 + 非游侠笨拙;必要时再加区容量上限、少数敌人反走位(`Root`/打人数最少的区)。

### 5.3 移动

- **基础移动人人有**:每人每回合可花能量挪自己一步(不占卡),保底自救。
- **移动牌**:牌库里也有移动牌(走一步 + 带触发)。
- 移动模型 = **自己独立进出某个区**(现引擎已改成这样,不再和队友换位)。

  > ⚠️ 这里和 v1 有出入:v1 想要"相邻交换、牵动队友、挡刀博弈";现引擎是"自己单独移到某区,不牵动别人"。**独立移动更契合"一区多人"的两区模型**,但 v1 那种"换位暴露队友"的戏剧性没了。**需要你拍板留哪个。**

### 5.4 百相（签名天赋）

- 定义 build 的天赋系统,升级三选一(数据源 `#UpgradeOptions`)。
- 每角色开局自带一条招牌百相。例:
  - 游侠:每回合第一张移动牌免费。
  - 法师:允许同回合挂 2 张执行牌。

## 6. 起手卡组的设计约束（写卡时照这个来）

给每个职业一套约 10 张的起手牌组,遵守:

| 职业 | 能量池 | 典型每回合 | 卡费区间 | 主类型 | 招牌效果 |
|---|---|---|---|---|---|
| 法师 | 4 | 打 1 张大的(＋1 张小支援) | 执行牌 3~4,支援 0~1 | 执行为主 | 情境答案 / 点杀 / 控制 |
| 战士 | 3 | 打 2 个稳的 | 1~2 | 全即时 | 护甲 / 嘲讽 / 打断 |
| 游侠 | 2 | 移动＋甩若干刀 | 移动付费,攻击 0 费 | 全即时 | 小刀 / 毒 / 闪避 / 移动触发 |

## 7. 执行线待办（audit 结果,不阻塞设计）

写卡时可以假装它们都работает;但下面这些**目前在战斗里是空的或接错系统**,phase-2 补：

1. **闪避 `Dodge` 完全没被消费**——卡能给闪避层数,但受击时没有任何地方检查它。游侠"移动→闪避续命"这半边现在**不存在**。
2. **打断接在死掉的意图轴上**——`InterruptCommand` 和 `破韧/格挡` 的打断都判定 `EnemyPhase.IntentAxis`,而敌人现在走的是 ATB 执行轨(`ExecuteAxis`),`InterruptCommand` 还**显式拒绝**执行轨。战士"唯一稳定打断"这条身份**目前打不到真敌人**,要改判定到执行轨。
3. **嘲讽索敌未确认**——`TauntCommand` 在,但要确认敌人分区索敌真的会读 `Taunted` 改目标。
4. **过载代价旧实现脱节**——`ApplyOverloadPenalty` 的 0–100 负债与离散队列对不上,要重写成"重排时额外 +N 格"。
5. **速度语义/数值**——正常回合结束改成按速度重排(而非卡费);把法师改成最慢。
6. **手牌抽牌数**——表里 `Draw:4`,实际按 5 走,改表。
